# 决策使用记录

用途：这张图谱不是展示品，是操盘时查依据的底座。每次用它做决定，留一条记录；下一次遇到同类问题，先翻这里。

- **决策类别**（六选一）：整体规划 / 方向选择 / 选题 / 脚本审查 / 报价边界 / 复盘归因
- **判定只分三档**：
  - `有源可对外断言`：有文献、官方口径、记录原文或可复核数据，能直接说。
  - `无源但可实测`：现在没有依据，但发出去/做一次就能用后台数据验证。
  - `无源且不可验证`：没有依据，也没有可执行的验证动作，只能当个人判断，不能当事实。
- **审计口径**：图谱里 `evidence=inferred` 的节点正在审计，本记录遇到时标「待审计确认」，暂不当依据用。`sourced` / `boundary` 才作为依据；`boundary` 引用时必须带限制条件。

# 产品边界与非目标

- 版本：v1.0（阶段 2 设计基线）
- 日期：2026-11-15
- 对应：Issue #1 / Issue #3

## 1. 产品定义

一个以商业结果为导向、以证据和推理为基础、运行在 Trae 中的监督式自主商业操盘手 Agent 系统。

它不是单纯问答机器人、内容生成器、知识库聊天入口或个人 IP 运营工具。它应当能够把模糊商业问题转化为明确任务，组织必要研究和专家分析，形成可审查决策，并推动授权范围内的执行与复盘。

## 2. 服务对象与任务范围

### 2.1 通用任务对象

- 企业：战略调整、竞争策略、经营诊断、增长与转型。
- 产品：市场定位、产品组合、上市策略、定价和生命周期。
- 项目：商业可行性、客户方案、投标策略、交付经营和项目复盘。
- 个人业务：自由职业、顾问服务、个人品牌及小微业务。

### 2.2 第一版覆盖的五类能力

1. 战略分析与资源配置。
2. 行业、市场与竞争分析。
3. 客户、产品、品牌与营销策略。
4. 经营、财务、组织与交付诊断。
5. 商业决策、风险审查与执行计划。

### 2.3 首个场景包

个人 IP 商业操盘作为独立场景包接入。它可复用通用战略、竞争、营销、经营与决策能力，并加载账号平台规则、内容运营方法、个人表达偏好和个人专属资料。该场景包不得反向改变通用宪法。

## 3. 输入与输出

### 输入
- 用户目标、问题描述、决策期限和约束。
- 企业/产品/项目背景及可用业务数据。
- 用户提供的材料、文件、链接和授权范围。
- 外部公开来源、访谈或实验数据（按任务需要获取）。
- 可选的行业知识、项目知识和个人知识。

### 输出
- 问题定义与任务边界。
- 事实/推断/假设/未知台账及证据出处。
- 必要的专家分析和分歧记录。
- 备选方案、收益/成本/风险和关键假设。
- 推荐决策、审批事项、执行计划和指标。
- 复盘结论及知识回写候选。

## 4. 产品质量属性

- 可追溯：重要事实与判断可追溯到来源和定位。
- 可校正：新证据进入后能识别受影响的结论并修正。
- 可控：权限、审批和执行范围明确。
- 可组合：专家与 Skills 按需组合，不强制全员出场。
- 可迁移：不依赖个人 IP 资料也能分析通用商业案例。
- 可复现：评测记录模型、提示、工具、资料快照和参数版本。
- 高效：简单任务走轻流程，复杂/高风险任务增加审查。

## 5. 不做什么

第一版明确不做：

- 独立 Web/桌面前端或 SaaS 产品。
- 独立 Agent 后端、运行时、消息总线或自研调度器。
- 自研多智能体编排引擎。
- 将全部知识正文塞入常驻 Rules。
- 让个人身份、人设或平台流量目标凌驾于商业目标。
- 强制每个任务调用六类专家或完整执行道法术器。
- 将所有结论强制进行三轮自驳；按风险分级触发。
- 将原七张 SOP 表强加给所有任务。
- 未经评测就把当前 RAG 当作可靠的自动决策依据。
- 自动执行资金支出、对外发布、合同承诺或不可逆操作。

## 6. 自主权与人工控制矩阵

| 行为 | 默认权限 | 约束 |
|---|---|---|
| 公开资料检索 | 自主 | 遵守访问限制、来源记录 |
| 内部知识检索 | 自主 | 依照数据权限与授权级别 |
| 分析、推演、方案草拟 | 自主 | 明确事实与假设边界 |
| 内部文件创建/修改 | 授权范围内自主 | 重要文件保留版本/差异 |
| 访问受限系统或敏感数据 | 需授权 | 最小权限、限定范围 |
| 对外发送信息/发布内容 | 必须审批 | 展示完整内容、渠道、受众 |
| 资金支出、投资、采购 | 必须审批 | 展示金额、对象、预算和风险 |
| 合同签署、报价承诺 | 必须审批 | 不代替法律/商业授权人 |
| 删除/覆盖重要数据 | 必须审批 | 先备份、展示影响范围 |
| 高风险/不可逆经营动作 | 必须审批 | 提供反方审查和退出条件 |

## 7. 关键成功指标

不以 Agent 数量或文档数衡量。第一版以以下能力验收：

- 无个人资料条件下完成四类通用商业案例。
- 事实引用准确、来源可追溯，未知不伪装成事实。
- 能按任务复杂度选择专家并处理观点冲突。
- 重大决策能够触发人工审批，不越权执行。
- 决策能形成有责任人、期限、指标和退出条件的执行计划。
- 注入反向证据后能合理修正判断。
- 个人 IP 场景作为独立用例通过，不污染通用能力。

## 8. 产品边界变更

任何新增能力需说明：用户问题、业务价值、Trae 原生能力是否可满足、运行成本、权限风险、维护负担、验收方式。若要引入独立服务或自研组件，必须形成新的架构决策并由用户明确批准，不得以实现便利为由扩张范围。

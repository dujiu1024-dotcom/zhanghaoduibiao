# 专家协作与文件黑板协议

## 1. 设计原则

黑板是每个商业任务的唯一显式协作状态面。总控负责创建、更新、审查和归档；专家读取被派发的上下文并提交独立产出。不得假设专家之间共享隐式上下文、互相调用或自动同步状态。

## 2. 标准目录

```text
work/cases/<case_id>/
├── 00-任务简报.md
├── 01-状态与派单.md
├── 02-事实与证据台账.md
├── 03-假设与未知.md
├── 04-专家分析/
│   ├── strategy.md
│   ├── competition.md
│   ├── marketing.md
│   ├── operations.md
│   ├── research.md
│   └── challenge.md
├── 05-争议与冲突.md
├── 06-决策审查.md
├── 07-最终决策.md
├── 08-执行计划.md
├── 09-监控记录.md
├── 10-复盘记录.md
└── 99-归档清单.md
```

文件不要求每个任务全部生成。简单任务允许只保留任务简报、证据/分析、最终结论和归档摘要。

## 3. 文件职责

| 文件 | 唯一职责 | 更新责任 |
|---|---|---|
| 00 任务简报 | 目标、边界、约束、成功标准 | 总控 |
| 01 状态与派单 | 状态机、专家任务、依赖和阻塞 | 总控 |
| 02 事实与证据 | 可核验事实及来源 | 研究专家/总控 |
| 03 假设与未知 | 未证实前提、未知和验证动作 | 全体提交，总控维护 |
| 04 专家分析 | 各角色独立专业判断 | 对应专家 |
| 05 争议与冲突 | 结论冲突、证据冲突、口径冲突 | 总控 |
| 06 决策审查 | 反方挑战、风险、备选与退出条件 | 决策审查专家 |
| 07 最终决策 | 总控综合、推荐和审批状态 | 总控 |
| 08 执行计划 | 获批行动、负责人、期限、指标 | 总控/执行负责人 |
| 09 监控记录 | 进展、偏差、触发条件 | 总控/执行负责人 |
| 10 复盘记录 | 结果、归因、经验候选 | 总控 |
| 99 归档清单 | 文件版本、遗留事项和敏感级别 | 总控 |

## 4. 状态机

`received → scoped → researching → analyzing → challenging → decision_ready → awaiting_approval → authorized → executing → monitoring → reviewed → closed`

可跳过不适用阶段，但必须在状态记录中说明原因。异常状态：`blocked`、`rejected`、`cancelled`。

每次变更记录时间、状态、操作者、理由、产物和下一动作。

## 5. 冲突处理

冲突类型：
- 事实冲突：来源对同一事件/指标描述不一致；
- 口径冲突：定义、单位、时间范围或计算方式不同；
- 推断冲突：事实相同但因果解释不同；
- 价值冲突：目标/偏好/风险容忍度不同；
- 方案冲突：对行动路径判断不同。

处理顺序：
1. 记录冲突双方及各自依据；
2. 判断是否源于定义、时间、样本或口径差异；
3. 需要时派发研究专家补证；
4. 由相关专家给出各自最强论证；
5. 决策审查专家评估后果和可逆性；
6. 总控决定、保留分歧或升级用户；
7. 记录未解决部分对结论的影响。

禁止通过简单投票或专家数量多数决定事实真伪。

## 6. 版本与引用

- 每份文件有版本号、更新时间、状态和负责人。
- 新结论不得静默覆盖旧结论；应说明 supersedes 哪个版本及变化原因。
- 证据使用稳定 evidence_id；文件引用应带相对路径和定位。
- 外部网页记录 URL、标题、发布日期、采集日期和关键段落定位。
- 数据快照记录来源系统、导出时间、字段口径和脱敏状态。

## 7. 权限与安全

- 黑板按任务授权访问；客户/个人敏感数据最小化保存。
- 不将客户机密或个人信息复制到公共知识库。
- 对外动作和高风险执行必须有审批记录。
- 归档时记录保留期限、访问级别和删除/脱敏要求。

## 8. 关闭条件

任务关闭前确认：最终决策已记录；审批结果齐全；执行状态如实；关键证据可追溯；未解决风险与后续责任人明确；复盘是否需要执行已判断；归档清单完整。


## 9. Write 工具边界补充

第 3 节的“更新责任”定义业务归属，不意味着专家可直接覆盖共享文件。考虑到 Trae Write 工具是否具备路径级沙箱尚未在 CN 3.4.20 真机验证，所有专家统一只创建总控指定的独立交付文件，位于 `work/cases/<case_id>/04-专家分析/` 且文件名包含 task_id 与角色。事实台账、状态派单、冲突记录、最终决策、执行计划和归档清单由总控更新；专家需要补充这些内容时提交独立文件供总控审阅合并。禁止覆盖已存在文件及其他专家产物。路径不明或目标已存在时停止并标记 blocked。

## 反方审查报告

### 一、待决事项与风险定级

| 字段 | 内容 |
|---|---|
| **待决事项** | 将年度可用现金的 40% 投入一个尚未经过市场验证的新业务 |
| **决策人** | 企业所有者/CEO（待确认） |
| **决策期限** | 未指定（需用户确认） |
| **核心目标** | 新业务增长、分散风险、战略转型中的至少一个（待明确） |
| **风险等级** | **高风险**——40% 现金是大额投入，新业务未经市场验证 |
| **授权边界** | 反方审查角色——只挑战、不批准；不替决策人做最终决定 |

### 二、关键假设复核

以下是隐含在该决策中的核心假设。**每条假设都值得被挑战**。

| 编号 | 关键假设 | 挑战角度 | 反证/质疑 |
|---|---|---|---|
| A-01 | "40% 现金"的投入规模是合理的 | 为什么是 40% 而不是 20% 或 60%？这个数字从何而来？ | 未经论证的数字——没有基于新业务预期回报率、企业主业现金需求、可承受最大损失等任何量化分析 |
| A-02 | 剩余 60% 现金足以支撑主业正常运营 | 主业未来一年的现金需求是多少？有没有可能出现主业需要现金但钱被新业务套住的情况？ | 未提供主业现金预算——不知道 60% 是否够用 |
| A-03 | 新业务"值得"投入 | "值得"的判断标准是什么？有什么初步的市场信号支撑？ | 输入明确说"尚未经过市场验证"——没有信号支撑 |
| A-04 | 新业务可以按计划投入和产出 | 实际投入可能超预算、产出可能延期、市场反应可能不如预期 | 普遍的超预算/延期规律——大部分新业务 1.0 都会经历 |
| A-05 | 投入后即使失败，剩余 60% 现金也能让企业活下来 | 失败的影响是否仅限于财务损失？会不会牵涉管理层注意力分散、品牌伤害、关键员工流失等隐性成本？ | 隐性成本通常被低估——CEO 花在新业务上的时间是主业的机会成本 |
| A-06 | 当前是进入新业务的"好时机" | 时机选择的依据是什么？有没有时间窗口紧迫性？ | 无时间紧迫性信息——"现在投" vs "3 个月后投"的利弊不明 |

### 三、三个方案公平比较

#### 方案 A：全额投入 40% 现金

| 维度 | 分析 |
|---|---|
| **核心逻辑** | 快速进入、快速试错、快速学习；如果新业务真的有前景，可以抢占先机 |
| **收益（上行）** | 若新业务成功，40% 现金的投入可能带来倍数级回报；完整团队和资源投入，最大化成功率 |
| **风险（下行）** | 40% 现金可能全部或大部分亏损；主业现金安全垫变薄；管理层注意力被分散；可能陷入"沉没成本陷阱"——投了钱就不甘心止损 |
| **可逆性** | **低**——资金一旦投入（尤其是用于团队、固定资产、市场投放），退出时回收比例有限 |
| **假设依赖度** | 极高——6 条关键假设几乎全部依赖 |
| **适用条件** | 企业主业现金流充沛且稳定；决策人有 2-3 次新业务成功经验；新业务有明确的时间窗口紧迫性 |
| **不适用条件** | 主业正在下行期；决策人首次尝试新业务；无时间窗口紧迫性 |

#### 方案 B：低成本试点（投入 5-10% 现金）

| 维度 | 分析 |
|---|---|
| **核心逻辑** | 用最小投入验证核心假设，成功了再追加，失败了损失可控 |
| **收益（上行）** | 用低投入获取真实市场反馈；即使失败损失也在可承受范围内；为后续决策积累证据 |
| **风险（下行）** | 试点可能因投入太小而"做不起来"——不是市场不行，是没投够；试点周期可能太长，错过时间窗口 |
| **可逆性** | **极高**——试点资金用完即止，无需额外退出成本 |
| **假设依赖度** | 低——不依赖 A-01/A-04/A-05，只需要验证 A-03 |
| **适用条件** | 新业务未经市场验证（正是当前场景）；无明确时间窗口紧迫性；决策人愿意先看数据再决策 |
| **不适用条件** | 新业务有极强的时间窗口要求（如政策红利期即将结束、竞争对手即将进场） |

#### 方案 C：暂缓投入（不行动方案）

| 维度 | 分析 |
|---|---|
| **核心逻辑** | 等新业务有了市场验证信号再投入；用主业现金流继续养企业 |
| **收益（上行）** | 零新增风险；有更多时间观察市场、收集情报；若新业务真的成立，后续再进也有前车之鉴 |
| **风险（下行）** | 可能错过先发机会；竞争对手先占位；企业管理层逐渐失去新业务探索的紧迫感 |
| **可逆性** | **完全可逆**——相当于维持现状，不损失任何选项 |
| **假设依赖度** | 无 |
| **适用条件** | 主业仍有大量增长空间；新业务方向尚不清晰；企业现金安全垫不够厚 |
| **不适用条件** | 主业增长见顶、必须寻找第二曲线；新业务有明确时间窗口 |

#### 方案对比总结

| 维度 | 方案 A（全额 40%） | 方案 B（低成本 5-10%） | 方案 C（暂缓） |
|---|---|---|---|
| 上行收益潜力 | 最高 | 中 | 零新增 |
| 下行损失风险 | 最高 | 低 | 零新增 |
| 可逆性 | 低 | 极高 | 完全可逆 |
| 信息增益 | 高（但代价大） | 最高（代价最低） | 中（桌面研究） |
| 假设依赖 | 高 | 低 | 无 |
| 推荐度（反方视角） | ❌ 不推荐 | ✅ 推荐 | ⚠️ 次优（若主业有增长空间） |

**反方结论**：**方案 B（低成本试点）是当前最优选择**。在"新业务未经市场验证"的前提下，全额投入 40% 现金不符合"先验证再投入"的基本风控逻辑。

### 四、失败预演

#### 主要失败路径

| 编号 | 失败路径 | 概率（定性） | 早期信号 | 止损点 |
|---|---|---|---|---|
| F-01 | 新业务完全做不起来，40% 现金全部亏损 | 中高 | 3 个月后核心指标（用户量/订单量/转化率）仍为个位数；目标客户访谈中无真实购买意愿 | 试点 6 周后若核心假设全部不成立，立即停止 |
| F-02 | 新业务"半死不活"——能跑但不赚钱，持续消耗现金 | 高 | 6 个月后有稳定用户但毛利率为负；需要持续烧钱维持 | 若连续 3 个月现金流为负且无改善趋势，止损 |
| F-03 | 新业务成功但吸走主业关键资源 | 中 | 主业核心员工被调去新业务；主业增长放缓或下滑；CEO 70% 以上时间花在新业务 | 主业任何季度增长低于历史均值 50% 时触发警报 |
| F-04 | 竞争对手看到我们做新业务，加速进入并抢占市场 | 低-中 | 竞争对手开始招聘/注册新业务相关公司/发布相关内容 | 若竞争对手在 3 个月内推出同类产品，评估是否还有差异化空间 |
| F-05 | 现金耗尽导致主业危机 | 低 | 主业出现需要大额现金的场景（如设备紧急更换、供应链危机）但现金被新业务套住 | 主业现金储备低于 3 个月运营成本时，立即从新业务撤资 |

#### 失败概率的核心决定因素

1. **新业务是否"真需求"**——这是最大变量，也是最未知的变量
2. **决策人是否有新业务经验**——有经验的决策者失败率显著更低
3. **企业现金安全垫厚度**——40% 投入后剩余 60% 是否真的"安全"
4. **管理层注意力分配**——CEO 在新业务和主业之间的时间分配

### 五、阶段性拨款门禁

如果执行方案 B（低成本试点），建议分三阶段拨款，每阶段都有明确的通过/不通过门禁：

```
Phase 1：探索期（预计 8-12 周）
├── 拨款上限：年度可用现金的 5%（而非 40%）
├── 目标：验证 3-5 个核心假设（是否有真实需求、谁付费、付多少）
├── 门禁标准（全部满足才能进 Phase 2）：
│   ├── 至少 10 个付费客户（不是免费试用）
│   ├── 客户访谈中 70% 以上表示"真的有这个需求"
│   ├── 初步单价 > 初步单位可变成本
│   └── 管理层确认 Phase 1 暴露的所有关键风险已被识别
└── 不通过 = 立即停止，损失上限 5% 现金

Phase 2：验证期（预计 12-16 周）
├── 拨款上限：累计到年度可用现金的 15%（Phase 1 已用 5%，追加 10%）
├── 目标：验证商业模式是否可规模化
├── 门禁标准（全部满足才能进 Phase 3）：
│   ├── 月留存率 > 30%（或行业基准水平）
│   ├── 获客成本（CAC）可被客户生命周期价值（LTV）覆盖（LTV/CAC > 3）
│   ├── 至少 2 个可复制的获客渠道跑通
│   └── 主业未受显著影响（增速不低于历史均值 50%）
└── 不通过 = 立即停止，损失上限 15% 现金

Phase 3：扩张期（预计 6+ 个月）
├── 拨款上限：累计到年度可用现金的 40%（Phase 2 已用 15%，追加 25%）
├── 目标：规模化扩张
├── 门禁标准（决策人确认后才能执行）：
│   ├── Phase 2 所有指标稳定 3 个月以上
│   ├── 主业增速未受影响
│   ├── 已制定详细的扩张计划和风险预案
│   └── 决策人书面批准全额投入
└── 此阶段才达到"40% 现金"的投入规模
```

**关键设计原则**：
- 每一阶段的损失上限都是可承受的（5% → 15% → 40% 逐级递增）
- 每阶段都有明确的、可量化的通过/不通过门禁
- 任何阶段不通过，立即停止，不追加投入
- Phase 3 才达到原始决策的 40% 规模，而非一开始就投

### 六、暂停和退出条件

以下任一条件触发，应立即启动退出评估程序：

| 触发条件 | 退出动作 | 损失上限 |
|---|---|---|
| Phase 门禁连续 2 次未通过 | 停止所有新业务投入，团队转回主业 | 当前阶段已投入金额 |
| 主业现金储备 < 3 个月运营成本 | 立即从新业务撤资，回笼所有可回收现金 | 撤资回收比例（未知，取决于已投入形态） |
| 新业务核心假设被证伪（如目标客户明确表示不会付费） | 立即停止 | 当前阶段已投入金额 |
| 管理层时间分配导致主业增速下降超过 50% | 重新评估：要么调整新业务团队减少管理层介入，要么暂停新业务 | 视调整方案而定 |
| 竞争对手在 3 个月内推出同类产品且明显领先 | 评估：还有无差异化空间；若无则退出 | 当前阶段已投入金额 |

### 七、反方挑战意见汇总

| 编号 | 挑战项 | 严重度 | 反方意见 | 是否改变推荐 |
|---|---|---|---|---|
| CH-01 | 40% 投入规模未经论证 | **高** | 为什么是 40%？没有基于任何量化分析——既不是基于新业务 ROI 预期，也不是基于企业可承受最大损失。这个数字从何而来？ | 是——建议降到 5% 启动 |
| CH-02 | 新业务"未经市场验证"却要大额投入 | **高** | 在没有任何市场反馈的情况下投 40% 现金，本质上是"用大额资金买不知道什么东西"。这不符合"先验证再投入"的基本风控逻辑。 | 是——建议先用 5% 验证 |
| CH-03 | 60% 现金是否足够支撑主业 | **中** | 没有主业现金预算——不知道扣掉 40% 后剩余的钱能不能覆盖主业的运营、扩张、应急需求。 | 是——建议先做主业现金预算 |
| CH-04 | 隐性成本被忽略 | **中** | CEO 的时间、管理层注意力、品牌稀释风险、关键员工流失——这些隐性成本通常比财务损失更大，但从未被计入决策。 | 是——建议明确管理层时间分配方案 |
| CH-05 | 沉没成本陷阱风险 | **中** | 一旦投入，"已经花了这么多钱"会成为继续投入的理由，哪怕市场信号已经明确说"不行"。 | 是——建议预设严格的止损条款 |
| CH-06 | 没有"不行动"方案的对照 | **低** | 原始决策没有给出"如果不投这 40%，这笔钱会用在哪里"的替代方案——是继续投主业扩张？是作为安全垫？是分红给股东？ | 否——反方已明确方案 C（暂缓）作为对照 |

### 八、用户审批事项

**反方不替决策人批准任何投资**。以下事项必须由决策人亲自批准：

| 编号 | 审批事项 | 审批内容 | 风险等级 |
|---|---|---|---|
| APPR-B2-01 | **批准 Phase 1 试点启动** | 同意投入年度可用现金的 5% 启动探索期；确认 Phase 1 的门禁标准；确认试点团队负责人 | 低（损失上限 5%） |
| APPR-B2-02 | **批准 Phase 2 追加投入** | Phase 1 门禁全部通过后，同意追加到累计 15% | 中（累计损失上限 15%） |
| APPR-B2-03 | **批准 Phase 3 全额投入** | Phase 2 门禁全部通过后，同意追加到累计 40% | 高（累计损失上限 40%） |
| APPR-B2-04 | **批准任何阶段的退出决策** | 任何触发退出条件的场景，退出动作需决策人批准 | 低（是止损，不是新投入） |
| APPR-B2-05 | **批准不行动方案（方案 C）** | 若决策人看完反方意见后决定暂缓，需明确批准并确认现金用途 | 无风险 |

**明确不构成审批的事项**：
- 反方审查过程本身（属于内部决策支持）
- Phase 1 的内部准备工作（市场访谈、竞品调研、试点方案设计等）

### 九、最终反方立场

**反方不批准任何投资**。反方的角色是挑战和审查，最终决策必须由决策人做出。

但反方明确表达以下判断（置信度：中——基于定性推理，无该企业具体数据）：

1. **"40% 投入未验证新业务"在风控上是激进决策**——不符合"先验证再投入"的基本原则
2. **阶段性拨款（5% → 15% → 40%）是更审慎的路径**——既不放弃机会，又把损失上限控制在每一阶段
3. **决策人需要先回答三个前置问题再拍板**：
   - 主业未来 12 个月的现金需求是多少？扣掉 40% 后剩的够不够？
   - "新业务成立"的最核心证据是什么？我凭什么相信它能成？
   - 如果新业务全亏了，企业能活下来吗？决策人能承受这个心理压力吗？

```
name: commercial-decision-review
description: 当任务需要比较重大方案、挑战核心假设、审查不可逆决策或检查审批门禁时触发。

# 商业决策与反方审查

## 执行步骤
1. 明确待决事项、决策人、期限、目标和风险等级。
2. 复核事实、证据质量、关键假设和口径。
3. 生成推荐方案、最强替代方案和不行动方案。
4. 预演失败，列出主要失败路径和早期信号。
5. 搜索反证、替代解释和遗漏利益相关方。
6. 对关键变量做情景/敏感性分析，检查下行损失和可逆性。
7. 明确审批要求、止损阈值、退出条件和残余风险。
8. 形成挑战意见并说明是否改变推荐。

## 可用模型
预演失败；反证检索；决策树；敏感性分析；风险矩阵。
```

## Skill 执行自检

| 检查项 | 状态 | 说明 |
|---|---|---|
| 是否比较了三个方案 | ✅ | 全额投入 / 低成本试点 / 暂缓 |
| 是否开展了失败预演 | ✅ | 5 条失败路径，每条有早期信号和止损点 |

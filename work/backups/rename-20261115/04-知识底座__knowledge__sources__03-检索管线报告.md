## 四、代理通了以后的批量灌库流程（先不执行）

1. **批量抓取**：按 metadata 待办表逐条请求，超时 60s、重试 2 次、限速 1 请求/2 秒；失败写入 `work/failed.csv` 并记 HTTP 码。
2. **判形态**：响应头 `Content-Type` 含 pdf → 用 **`/opt/homebrew/opt/poppler/bin/pdftotext -layout`**（poppler 不在默认 PATH，必须写绝对路径；已固化进 `pipeline/ingest.py` 的 `PDFTOTEXT` 常量）；抽出的文本若"每行长度方差大 + 含大量单字符行"判为扫描 OCR，质量降为`仅参考`，**不摘原文**。
3. **抽正文**：HTML 用 Readability 类规则（保留 h1-h4、p、li、blockquote），丢弃 nav/footer/aside；PDF 保留章节标题。
4. **去页眉页脚**：统计每页首尾 3 行出现频次，跨页重复 ≥60% 的行删除；再删页码正则 `^\s*[-—]?\s*\d{1,3}\s*[-—]?\s*$`。
5. **分章**：优先用目录（PDF outline / h1-h2）切；无目录则按 `第[一二三四五六七八九十百零\d]+[编章节条]` 与字号突变切。
6. **页码映射**：`pdftotext` 时按页输出（`-f/-l` 分页），每段落记录 `页码 = 当前页`；HTML 源记 `章节`不记页码。
7. **建索引**：重跑 `ingest.py` → `build_index.py --build`；每次重建前把旧 `index/` 改名归档，保留可回溯版本。
8. **抽检**：每批随机抽 5 段，人工核对"段落原文 vs 源文件"是否一致；不一致率 >2% 则整批回退。

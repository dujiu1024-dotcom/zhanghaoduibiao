# K1-K5 取证计划四要素核对

> run_id: rerun-v1.1-20261116-001

核对标准：规范 7.3 节要求 K1-K5 每条独立呈现四列——`需要的数据`、`取得方法`、`责任角色`、`决策用途`。决策用途必须具体说明该数据如何影响 A 直营、B 渠道试点、C 暂缓中的选择或某项门槛。

## K1：新城市烘焙市场竞争格局

| 要素 | 总控输出内容 | 核对结果 |
|---|---|---|
| 需要的数据 | 核心商圈现有烘焙品牌清单、各自门店数量、产品定位、价格带 | ✓ 明确 |
| 取得方法 | 委托当地兼职市场调研员或外包团队，2-3 天完成商圈步行扫街；同时查大众点评/美团/抖音本地号的品牌露出 | ✓ 明确且可执行 |
| 责任角色 | 竞争专家负责方案设计和结果解读；市场调研员执行 | ✓ 明确 |
| 决策用途 | 直接决定方案 A 是否成立——如果已有 3+ 强势品牌且定位清晰，直营进入的竞争压力显著增大，方案 A 的风险等级上调；如果竞争分散，方案 A 的可行性上调 | ✓ 直接影响方案选择，具体说明了如何影响 |

**四要素齐全** ✓

## K2：核心商圈租金与客流

| 要素 | 总控输出内容 | 核对结果 |
|---|---|---|
| 需要的数据 | 目标商圈核心位置商铺租金（元/㎡/月）、日间高峰时段（10:00-12:00, 16:00-18:00）人流量（人次/小时） | ✓ 明确且可量化 |
| 取得方法 | 联系当地商业地产中介索要报价；派人在目标点位计数 2 个完整高峰日 | ✓ 明确且可执行 |
| 责任角色 | 战略专家负责点位选择和数据解读；中介和兼职计数员执行 | ✓ 明确 |
| 决策用途 | 直接验证 H-S1 和 H-S2——租金数据影响单店投资额和盈亏平衡线；客流数据直接判断"是否足以支撑门店模型"。如果两项均达标，方案 A 的核心假设获得实证支撑 | ✓ 直接影响方案 A 的核心假设验证 |

**四要素齐全** ✓

## K3：当地可合作渠道清单

| 要素 | 总控输出内容 | 核对结果 |
|---|---|---|
| 需要的数据 | 当地成熟的商业综合体/社区超市/咖啡茶饮店等零售点位清单，以及是否愿意接受 8 周合作试点的初步意向 | ✓ 明确 |
| 取得方法 | 通过当地人脉或行业协会联系渠道方，发送简短合作意向函（不涉及任何承诺）；同时实地走访 10-15 个候选点位 | ✓ 明确且可执行 |
| 责任角色 | 竞争专家负责筛选渠道和初步沟通；行政/运营执行 | ✓ 明确 |
| 决策用途 | 直接决定方案 B 是否可执行——如果找到 2+ 愿意配合的渠道，方案 B 进入可执行状态；如果找不到，方案 B 直接排除，在 A 和 C 之间选择 | ✓ 直接影响方案 B 的可执行性，且说明了排除后的分支 |

**四要素齐全** ✓

## K4：产品偏好快速验证

| 要素 | 总控输出内容 | 核对结果 |
|---|---|---|
| 需要的数据 | 目标客群对本企业核心产品的接受度（是否愿意尝试、愿意支付的价格区间、偏好的品类） | ✓ 明确 |
| 取得方法 | 在 K2 计数客流的同一商圈做 50-100 份街头问卷调查（3 分钟内完成，送小样品）；或与 K3 的渠道试点绑定，用试点期间的真实销量做初步判断 | ✓ 明确，给出了两种可选路径 |
| 责任角色 | 竞争专家负责问卷设计和结果分析；兼职调研员执行 | ✓ 明确 |
| 决策用途 | 验证竞争专家 H-C2（消费者偏好尚未验证）——如果接受度高，方案 A 和 B 都获得支撑；如果接受度低，方案 A 和 B 的风险都上调，方案 C 的优先级上调 | ✓ 直接影响 A/B/C 的优先级排序 |

**四要素齐全** ✓

## K5：6 个月现金消耗速度确认

| 要素 | 总控输出内容 | 核对结果 |
|---|---|---|
| 需要的数据 | "6 个月运营"的现金流测算：如果开 2 家直营，前 6 个月每月现金流出预计是多少；如果维持现状（仅做取证工作），每月现金流出是多少 | ✓ 明确，给出了两种情景 |
| 取得方法 | 由企业财务团队基于历史直营店数据做两种情景的现金流测算 | ✓ 明确，利用已有资源 |
| 责任角色 | 企业财务负责人 | ✓ 明确 |
| 决策用途 | 给所有方案设定硬约束上限——如果直营情景下 6 个月现金会提前耗尽，方案 A 的执行期限必须缩短（如改为 4 个月）或放弃；如果维持现状现金足够支撑取证工作，则方案 B 和 C 的财务安全垫更厚 | ✓ 给所有方案设定硬约束，影响期限和放弃判断 |

**四要素齐全** ✓

## 二、可计算指标（当前数据充足）

### 2.1 单客户月贡献（Unit Contribution Margin, Monthly）

**定义**：单客户在一个月内为公司贡献的利润（未分摊固定费用和获客成本）

**公式**：

```
单客户月贡献（元/客户·月） = 月订阅价 - 每客户月变动服务成本
```

**代入**：

```
= 500 - 180
= 320 元/客户·月
```

**结论**：✅ 可计算。净收入（月订阅价扣除折扣退款）尚不确定，当前结果基于零折扣零退款假设。

### 2.2 月贡献毛利率

**公式**：

```
贡献毛利率 = 单客户月贡献 / 月订阅价 × 100%
          = 320 / 500 × 100%
          = 64%
```

**结论**：✅ 可计算（基于零折扣零退款假设）。

### 2.3 盈亏平衡客户数（Break-even Number of Customers）

**定义**：在给定固定费用和单位贡献下，覆盖全部固定费用所需的活跃客户数。此处为**经营盈亏平衡**（operating break-even），不包含获客成本回收。

**公式**：

```
盈亏平衡客户数（个） = 每月固定运营费用 / 单客户月贡献
```

**代入**：

```
= 48,000 / 320
= 150 个客户
```

**敏感性分析**（固定费用变化 ±10%）：

| 固定费用 | 单客户月贡献 | 盈亏平衡客户数 |
|----------|-------------|---------------|
| 43,200（-10%） | 320 | 135 个 |
| 48,000（基准） | 320 | 150 个 |
| 52,800（+10%） | 320 | 165 个 |

**单客户月贡献变化敏感性**（固定费用 48,000 保持不变）：

| 单客户月贡献 | 订阅价 | 变动成本 | 盈亏平衡客户数 |
|-------------|--------|---------|---------------|
| 280 元 | 500 | 220（+22%） | 172 个 |
| 320 元（基准） | 500 | 180 | 150 个 |
| 360 元 | 500 | 140（-22%） | 133 个 |
| 320 元 | 450（-10%） | 130 | 150 个 |

**结论**：✅ 可计算经营盈亏平衡客户数。这是"覆盖固定月支出"所需客户数，未包含获客成本回收，也未考虑客户流失。

## 三、不可直接计算的指标及所需条件

### 3.1 获客成本回收期（CAC Payback Period）

**不可直接计算的原因**：客户平均订阅期限未知（U1）、现金回款周期未知（U2）。

**公式（需补充数据后）**：

有两种口径，需明确选择：

**口径 A：利润口径回收期（每月均摊）**

```
回收期（月） = 获客成本 / 单客户月贡献
             = 1,200 / 320
             = 3.75 个月
```

⚠️ **此口径有隐含假设**：客户订阅期限 ≥ 3.75 个月，且获客成本在首月一次性支出。实际回收期应取 `max(上值, 客户实际留存月数)`，但若客户流失快于 3.75 个月，则贡献不足覆盖 CAC。

**口径 B：现金口径回收期（逐月累加净现金流入）**

```
第 n 个月累计净现金流入 = Σ(k=1 to n) (月订阅价 - 月变动成本 - 获客成本/n) × 客户数
```

实际现金回收期取决于：
1. 获客成本支出时点（假设：首月一次性支出 1,200 元/客户）
2. 订阅费收款时点（假设：月初预收 500 元/客户）
3. 变动成本支付时点（假设：月末支付 180 元/客户）

**当前条件下能做的**：给出"假设客户留存超过 N 个月时的回收期"，但**不能编造 N**。

### 3.2 客户生命周期价值（LTV）

**不可直接计算的原因**：客户平均订阅期限未知（U1）。

**公式（需补充数据后）**：

```
LTV（毛利口径） = 单客户月贡献 × 平均订阅期限（月）
LTV（净现口径） = Σ(k=1 to N) 单客户月贡献 / (1+折现率)^k  ， N = 平均订阅期限
```

### 3.3 LTV/CAC 比值

**不可直接计算的原因**：LTV 不可计算（缺 U1）。

## 四、收入 / 利润 / 现金三口径分离

### 4.1 月度利润结构（客户数 = Q）

```
月度收入（元/月）        = 500 × Q                    （零折扣零退款假设）
月度变动成本（元/月）    = 180 × Q                    （线性假设）
月度贡献毛利（元/月）    = 320 × Q                    （收入 - 变动成本）
月度固定费用（元/月）    = 48,000
月度营业利润（元/月）    = 320 × Q - 48,000           （贡献毛利 - 固定费用）
```

### 4.2 月度现金结构（区别于利润）

**未知**：

### 5.2 乐观情景（Optimistic）

**需要明确**：在哪些变量上"乐观"。乐观通常指：
- 订阅期限更长（LTV 提升）
- 月流失率更低
- 变动成本下降（例如 180 → 150 元/客户·月）
- 获客成本下降（例如 1,200 → 900 元）
- 固定费用控制（48,000 → 42,000 元）
- 零退款零折扣

**不能编造**：乐观情景下的具体数值（例如"假设平均订阅 24 个月"）— 这必须由用户或数据提供方给出。

### 5.3 悲观情景（Pessimistic）

**需要明确**：在哪些变量上"悲观"。悲观通常指：
- 客户流失快（订阅期限 < 回收期 3.75 月）
- 退款/折扣侵蚀净收入（例如 10% 退款率 → 实际收入 450 元/客户·月）
- 变动成本上升
- 固定费用超支
- 获客成本超支
- 回款周期延长（现金紧张加剧）

## 七、关键判断与预警

### 7.1 已确认的事实判断
- 单位经济毛利 64%，单客户月贡献 320 元 — 作为独立指标是健康的
- 经营盈亏平衡客户数 150 个 — 规模门槛较低
- 若客户留存 ≥ 3.75 月，利润口径下 CAC 可回收

### 7.2 核心风险
1. **客户流失风险**（U1）：若客户平均订阅 < 3.75 月，获客成本无法回收，每获客一个净亏损
2. **现金风险**（U2）：若订阅费不是月初预收而是滞后，且获客成本首月全额支出，会产生阶段性现金缺口
3. **定价折扣侵蚀**（U3）：若有 10% 折扣，净收入从 500 降至 450，单客户贡献从 320 降至 270，盈亏平衡客户数上升至 178 个
4. **获客成本膨胀**：CAC 暂估 1,200，实际可能超出预算

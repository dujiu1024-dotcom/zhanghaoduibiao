# B1 商业诊断：虚构区域连锁轻食店

**业务对象**：虚构区域连锁轻食店  
**诊断期间**：最近三个月（同比对比）  
**用户提供事实**：营业收入同比增长 18%，净利润同比下降 12%，现金余额连续下降  
**数据缺口**：无门店级数据、订单结构、折扣、平台佣金、人工排班、库存损耗、应收应付明细  
**诊断角色**：独立会话执行器（手动参照 business-diagnosis SKILL.md）

---

## 一、口径核验（阻塞项，必须先做）

以下三项指标均为用户提供，**在确认口径之前，任何对比结论都不可靠**：

| 指标 | 用户给出的数值 | 需要验证的口径项 | 状态 |
|------|---------------|-----------------|------|
| 营业收入 | 同比 +18% | ① 是否含退款/取消？② 是否含税费？③ 门店合并范围是否与去年同期一致？④ 开业不到一年的新店是否计入同期对比？⑤ 收入确认时点（现金/下单/取餐）？ | 待确认 |
| 净利润 | 同比 -12% | ① 会计制度（收付实现制/权责发生制）？② 是否含一次性损益（装修摊销、补贴、罚款）？③ 融资成本、税费是否计入？④ 折旧摊销政策是否有变化？⑤ 营业利润与净利润之间的差额构成？ | 待确认 |
| 现金余额 | 连续下降 | ① 是经营现金流还是总现金余额？② 是否含投资/筹资活动现金流？③ 账期内应付/应收的变化方向？④ 现金下降幅度与净利润下降幅度是否匹配？ | 待确认 |

> **关键纪律**：仅凭"收入增长、净利润下降、现金下降"三个现象，只能确认三者走势存在背离，**不能直接断言成本增速必然超过收入增速**，也不能直接锁定营销、人工、平台佣金或某一部门为根因。三个指标必须拆开处理。

## 二、业务系统图（轻食店简化版）

```
客户 → 多渠道（门店堂食/外卖平台/私域/团餐） → 下单交易 → 履约（备货→制作→配送/自取） → 收款
                                                                    ↓
                                                          食材采购→库存管理→损耗
                                                                    ↓
                                                          人工排班→制作效率
                                                                    ↓
                                                          固定成本（租金/折旧/管理）
                                                                    ↓
                                                          平台佣金/折扣/退款
```

## 三、指标树

### 3.1 结果指标（按诊断优先级排列）

```
净利润（结果指标 #1，同比 -12%）
├── 营业利润
│   ├── 营业收入
│   │   ├── 订单数 × 平均订单净额
│   │   │   ├── 订单数（驱动指标：客流/流量/复购）
│   │   │   └── 平均订单净额 = 标价 - 折扣 - 平台佣金 - 退款/取消
│   │   └── 收入结构（门店/渠道/产品线占比变化）
│   └── 营业成本与费用
│       ├── 直接成本（食材/包装/耗材，随订单量变动）
│       ├── 变动履约成本（制作人工/配送费，随订单量变动）
│       ├── 渠道费用（平台佣金/第三方配送费）
│       ├── 固定运营成本（租金/折旧/管理/固定人工）
│       └── 期间费用（营销/办公/差旅）
├── 非经营性损益（一次性/投资/融资/税费）
└── 净利润

经营现金流（结果指标 #2，连续下降）
├── 经营利润（同上）
├── 营运资本变动
│   ├── 应收账款变化（平台回款周期/团餐账期）
│   ├── 存货变化（库存积压/损耗上升导致资金占用）
│   └── 应付账款变化（供应商账期缩短/预付增加）
└── 非现金项目（折旧摊销、应计费用）

现金余额（结果指标 #3，连续下降）
├── 经营现金流（见上）
├── 投资现金流（新店装修/设备采购）
└── 筹资现金流（股东投入/借款/还款）
```

### 3.2 指标类型区分

| 层级 | 指标 | 类型 | 说明 |
|------|------|------|------|
| L1 | 营业收入、净利润、现金余额 | 结果指标 | 用户给出的原始观察值 |
| L2 | 订单数、平均订单净额、营业成本、营运资本 | 一阶驱动指标 | 直接影响 L1，需数据验证 |
| L3 | 客单价标价、折扣率、平台佣金率、食材成本率、人工效率、库存周转天数 | 二阶驱动指标 | 可通过数据拆解验证 |
| L4 | 渠道结构、产品线毛利结构、新客占比、复购率 | 结构性驱动指标 | 需订单明细才能拆分 |

## 四、根因假设

以下假设**均为未验证**，每个假设独立、可证伪，不预设因果。

### 假设 A：收入质量下降（驱动指标层）

| 属性 | 内容 |
|------|------|
| **假设描述** | 收入增长主要来自高折扣渠道/低毛利产品线/新客低质量订单，导致平均订单净额（扣除折扣、佣金、退款后）的增速低于订单数增速，甚至可能同比下降 |
| **推理链** | 收入账面 +18% → 如果折扣率/佣金率同比上升 → 净收入增速低于账面收入增速 → 毛利增速可能为负 |
| **所需证据** | ① 分渠道收入的标价、折扣率、平台佣金率、退款率；② 分产品线的标价与实际成交净额；③ 订单数 vs 平均订单净额的同比变化 |
| **可证伪方式** | 如果数据显示折扣率/佣金率同比持平或下降，且平均订单净额同比增长，则此假设被排除 |
| **影响评估** | 高（直接影响毛利和利润） |
| **可验证性** | 高（取订单明细和渠道对账数据即可验证） |

### 假设 B：直接成本增速超过收入增速（驱动指标层）

| 属性 | 内容 |
|------|------|
| **假设描述** | 食材成本率（食材采购额÷净收入）或包装耗材成本率同比上升，且未被收入增长覆盖 |
| **推理链** | 订单量增长 → 如果食材采购价格上涨（通胀/供应链问题/采购批量不足）或 损耗率上升（备货不准/订单不稳定）→ 食材成本率上升 → 毛利下降 |
| **所需证据** | ① 食材采购单价同比变化；② 分品类食材损耗率；③ 食材成本率（食材成本÷净收入）同比变化；④ 包装耗材成本率 |
| **可证伪方式** | 如果数据显示食材成本率同比持平或下降，则此假设被排除 |
| **影响评估** | 高（直接影响毛利，轻食行业食材成本通常占收入 30-45%） |
| **可验证性** | 高（取采购台账和库存盘点记录即可验证） |

### 假设 C：变动履约成本增速超过收入增速（驱动指标层）

| 属性 | 内容 |
|------|------|
| **假设描述** | 制作人工效率下降（单位订单耗时上升）、配送费（第三方）占比上升，或两者同时发生 |
| **推理链** | 订单量增长 → 如果排班未随订单量弹性调整（人效下降）或 外卖订单占比上升导致配送费增加 → 变动履约成本率上升 → 营业利润下降 |
| **所需证据** | ① 单位订单制作耗时同比；② 人工成本÷净收入 同比；③ 配送费÷净收入 同比；④ 门店高峰时段排班与实际订单量匹配度；⑤ 外卖订单占比同比变化 |
| **可证伪方式** | 如果数据显示人效持平/提升且配送费占比下降，则此假设被排除 |
| **影响评估** | 中高（人工+配送通常占收入 20-35%） |
| **可验证性** | 高（取排班表、POS 数据、配送对账单即可） |

### 假设 D：营运资本恶化导致现金流承压（现金流特定层）

| 属性 | 内容 |
|------|------|
| **假设描述** | 现金余额连续下降与利润下降并非同一原因，而是由应收账款回款变慢、库存积压或应付账款账期缩短导致的营运资本负向拉动 |
| **推理链** | 净利润下降 + 营运资本占用上升 → 经营现金流恶化速度快于利润恶化速度 → 现金余额连续下降 |
| **所需证据** | ① 应收账款周转天数同比（平台、团餐）；② 存货周转天数同比；③ 应付账款周转天数同比；④ 近三个月现金流量表（经营/投资/筹资三项分开） |
| **可证伪方式** | 如果数据显示经营现金流≈净利润（营运资本变动不大），或现金下降主要由投资活动（如新店装修）导致，则此假设被排除 |
| **影响评估** | 中（影响资金安全，但不一定是利润下降的根因） |
| **可验证性** | 高（取应收应付台账和现金流量表即可） |

### 假设 E：一次性项目或会计口径变化（排除层）

| 属性 | 内容 |
|------|------|
| **假设描述** | 净利润下降包含一次性损益（如大额罚款、装修摊销、员工遣散、政府补贴减少）或会计政策调整（如折旧年限变更、收入确认时点变更） |
| **推理链** | 如果净利润下降中 100% 由一次性项目解释，则营业利润可能并未恶化 |
| **所需证据** | ① 净利润与营业利润之间的差额明细（非经常性损益、融资成本、税费）；② 近三个月是否有大额一次性支出或补贴减少；③ 会计政策是否在期间有变更 |
| **可证伪方式** | 如果净利润下降额中一次性项目占比 <20%，或营业利润也同比下降，则此假设不能解释全部现象 |
| **影响评估** | 中（如果成立，意味着核心业务并未恶化，需要聚焦解释一次性项目的原因） |
| **可验证性** | 高（取利润表明细和会计政策说明即可） |

### 假设 F：新店扩张导致固定成本前置（结构性层）

| 属性 | 内容 |
|------|------|
| **假设描述** | 同期开设了新门店，新店在爬坡期（收入贡献低于固定成本），拉低了合并净利润；新店装修和设备采购的现金支出也导致现金余额下降 |
| **推理链** | 如果合并范围包含新店 → 新店固定成本（租金、折旧、人工）已发生但收入未达预期 → 合并净利润被稀释 → 新店装修/设备采购属于投资现金流 → 现金余额下降 |
| **所需证据** | ① 近三个月是否有新店开业；② 合并范围是否与去年同期一致；③ 各门店收入/成本明细；④ 投资现金流（装修/设备）明细 |
| **可证伪方式** | 如果合并范围稳定、无新店开业，则此假设被排除 |
| **影响评估** | 中高（解释利润和现金两个现象，且影响是长期性的） |
| **可验证性** | 高（取门店清单和装修合同即可） |

### 假设 G：固定运营成本刚性上升（驱动指标层）

| 属性 | 内容 |
|------|------|
| **假设描述** | 租金上涨（续租调价）、管理费用（总部人员/办公）上升、或折旧摊销增加，且这些成本不随订单量变动 |
| **推理链** | 固定成本上升 → 收入增长不足以覆盖 → 营业利润下降 |
| **所需证据** | ① 租金合同（是否续租涨价）；② 管理费用明细同比；③ 折旧摊销计算表；④ 固定成本÷净收入 同比 |
| **可证伪方式** | 如果数据显示固定成本率同比持平或下降，则此假设被排除 |
| **影响评估** | 中 |
| **可验证性** | 高（取总账和租赁合同即可） |

## 五、假设排序（影响 × 可验证性矩阵）

| 排名 | 假设 | 影响程度 | 可验证性 | 建议取证优先级 | 理由 |
|------|------|---------|---------|---------------|------|
| 1 | E. 一次性项目或会计口径变化 | 中 | 高 | **立即排查** | 成本最低、最易排除；如果成立，其他假设可能不需要深入 |
| 2 | A. 收入质量下降 | 高 | 高 | **立即排查** | 直接回答"账面收入涨但实际赚到的钱是否在涨" |
| 3 | B. 食材成本率上升 | 高 | 高 | **立即排查** | 轻食行业核心成本项，影响重大 |
| 4 | F. 新店扩张导致固定成本前置 | 中高 | 高 | **立即排查** | 解释利润和现金两个现象，且只需确认是否有新店 |
| 5 | D. 营运资本恶化 | 中 | 高 | 第二批 | 解释现金下降，但不解释利润下降；需先完成 E/A/B |
| 6 | C. 变动履约成本上升 | 中高 | 高 | 第二批 | 影响大但取证量稍大，可等前三步结果缩小范围后再看 |
| 7 | G. 固定运营成本上升 | 中 | 高 | 第三批 | 如果以上均排除或部分解释，再看固定成本 |

> **排序逻辑**：先用最低成本排除"伪问题"（E），再用低成本验证"核心业务是否在赚"（A、B、F），最后逐步深入。

## 七、优先验证步骤

### 步骤 1：口径核验 + 一次性项目排除（1-2 天）

```
输入：利润表 + 现金流量表 + 门店清单
动作：
  a) 确认"营业收入+18%"和"净利润-12%"的会计口径是否一致
  b) 计算营业利润同比变化 → 如果营业利润也 -XX%，说明核心业务确实在恶化；如果营业利润持平但净利润 -12%，则问题全在非经常性损益（假设 E 成立）
  c) 拆分净利润与营业利润的差额 → 看非经常性损益占比
  d) 看现金流量表 → 现金下降是经营/投资/筹资哪项主导？如果是投资现金流（如新店装修），则利润和现金两个现象都可能由新店扩张解释（假设 F 强化）
  e) 确认门店合并范围
输出：口径确认结论 + 假设 E 和 F 的初步成立/排除判断
```

**如果假设 E 成立（一次性项目解释 >80% 净利润下降）** → 问题结束，转向处理一次性项目的根因。

**如果假设 F 成立（新店爬坡解释主要部分）** → 问题转为新店投入产出评估。

**如果 E 和 F 都不成立** → 进入步骤 2。

### 步骤 2：收入质量与直接成本（2-3 天）

```
输入：分渠道净收入 + 食材成本率
动作：
  a) 净收入 = 标价收入 - 折扣 - 平台佣金 - 退款 → 计算净收入同比增速 vs 账面收入增速
  b) 净收入增速 vs 食材成本增速 → 判断毛利是否在扩张还是收缩
  c) 分渠道看：哪个渠道在拉高收入？该渠道的折扣率/佣金率是否高于其他渠道？
输出：假设 A 和 B 的成立/排除判断 + 毛利同比变化的贡献拆解
```

### 步骤 3：根据前两步结果，决定是否深入假设 C/D/G

```
如果步骤 1+2 已解释 >80% 的利润下降 → 后续取数暂缓，转向方案设计
如果步骤 1+2 只解释了部分 → 有针对性地取假设 C/D/G 的数据
```

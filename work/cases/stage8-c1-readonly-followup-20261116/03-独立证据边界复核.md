# PR #56 证据边界复核备注

- 复核对象：本 PR 新增的 C1 只读取证补充材料
- 复核方式：仅检查本 PR 提交的文本差异；未访问用户本机、未读取数据库、未执行任何生产环境命令
- 复核结论：本补充材料可作为待核对的人工记录，不足以证明 C1 只读取证已通过

## 1. 采集时间字段未形成有效时间证据

以下两个文件把 shell 命令替换表达式原样写入文件，而不是命令执行后的时间值：

- `00-候选数据库清单.md`：`$(date -u +%Y-%m-%dT%H:%M:%SZ)`
- `01-进程与文件句柄.md`：`$(date -u +%Y-%m-%dT%H:%M:%SZ)`

因此，这两处采集时间均应判为 `NOT_RECORDED`，不能据此确定采集发生的具体时刻。不得用文件提交时间、其他文件时间或当前时间反向补填。

## 2. 进程与文件句柄结论缺少可复核原始输出

`01-进程与文件句柄.md` 写有“无相关进程”“无文件句柄占用”，但本 PR 差异未附对应命令、完整 stdout/stderr、退出码、过滤条件和采集时间。故这两项只能记录为报告者陈述，独立复核状态为 `NOT_VERIFIED`，不能据此证明采集时没有进程或文件句柄。

## 3. 哈希清单与元数据记录的证据边界

- `SHA256SUMS.txt` 是哈希值文本清单，不等于哈希命令实际执行过程的证据。
- `02-元数据与SHA256.md` 中记录的大小、mtime、模式和哈希值，在当前 PR 差异中缺少可供独立重算的原始文件快照。
- 本备注不判断这些值真伪，也不将其升级为独立验证事实。

## 4. 对 C1 状态的影响

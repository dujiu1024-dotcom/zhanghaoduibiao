# 六类专家 Subagent｜配置对照表

本文件是用户在 Trae 中配置总控与专家关系时的核对表。专家定义以仓库现有 `.trae/agents/` 文件为准；不要复制本表重新创建第二套专家，除非真机检查发现原配置缺失或不兼容。

| Subagent 名称 | 仓库配置文件 | 职责范围 | 不应越权承担 |
|---|---|---|---|
| strategy-expert | `.trae/agents/strategy-expert.md` | 战略定位、战略选择、增长路径、资源配置 | 独立批准最终战略或外部承诺 |
| competition-expert | `.trae/agents/competition-expert.md` | 市场结构、竞争者、替代方案、行业边界 | 把未经核验的市场信息当事实 |
| marketing-expert | `.trae/agents/marketing-expert.md` | 客户细分、价值主张、产品、定价、渠道、获客与留存 | 未经审批对外发布营销内容或承诺 |
| operations-expert | `.trae/agents/operations-expert.md` | 收入、成本、利润、现金流、交付、组织和效率 | 自主付款、交易或承诺资源 |
| research-expert | `.trae/agents/research-expert.md` | 动态事实、资料缺口、来源核验、证据台账 | 编造来源或将搜索摘要直接定为事实 |
| decision-challenger | `.trae/agents/decision-challenger.md` | 高影响、高不确定、不可逆决策的反方审查 | 代替用户作最终裁决 |

## 配置核对

- [ ] Trae 能识别六个 Subagent 文件。
- [ ] 总控具备调用 Subagent 的能力（以 CN 3.4.20 实际界面为准）。
- [ ] 每个 Subagent 的名称唯一、描述可路由。
- [ ] 工具权限遵循最小权限原则。
- [ ] 总控派单提供明确任务背景、输入文件、范围、证据要求和输出要求。
- [ ] 专家产物写入约定案例黑板或明确输出位置。
- [ ] 总控独立检查并接受/退回专家产物。
- [ ] 专家不能自行批准自己的结论或执行需要人工审批的动作。

若 Trae 版本不支持总控 Agent 调用 Subagent，记录为兼容性阻塞，不要声称已实现自动调度；可暂时由用户手动选择专家并按统一派单格式交接。

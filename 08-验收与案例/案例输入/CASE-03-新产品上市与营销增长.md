# CASE-03｜新产品上市与营销增长

> **测试数据声明：** 本案例中的企业、客户、产品和所有数字均为虚构模拟，不代表真实市场事实。

## 任务背景

启明供应链软件（虚构）准备推出一款 B2B 供应链异常预警模块。产品拟通过 ERP/WMS 数据识别交付延期、供应商质量异常和库存风险，并向采购、计划和供应链负责人提供预警。

## 产品与客户线索

- 初步目标名单约 500 家企业，由销售团队按公开信息整理，尚未去重或验证采购需求。
- 目前有 3 家企业参与试点，其中 2 家表示愿意继续试用，但均未签订付费合同；第 3 家认为预警准确性不足。
- 内部离线测试曾使用 50 条人工标注记录，得到约 82% 的预警准确率；样本来源、标签一致性和代表性尚未审查。
- 数据接入需要客户提供 ERP/WMS 接口权限，实施周期初步估计为 4–8 周。

## 商业假设

| 项目 | 初步假设 |
|---|---:|
| 年订阅价格 | 60 千元/客户 |
| 首次实施费 | 20 千元/客户 |
| 单客户实施直接成本 | 18 千元 |
| 年度服务直接成本 | 12 千元 |
| 过去 90 天目标客户触达 | 200 家 |
| 首次会议 | 46 家 |
| 产品演示 | 14 家 |
| 试点 | 3 家 |
| 付费签约 | 0 家 |
| 过去 90 天销售与营销费用 | 240 千元 |

以上转化数字由内部 CRM 导出，但线索去重规则、渠道归因和销售周期口径尚未统一。

## 团队与资源

- 产品研发 6 人，售前/销售 3 人，实施 2 人。
- 可投入上市专项预算上限 500 千元，超出须总经理审批。
- 当前交付团队最多同时支持 4 家试点客户。
- 目前没有经过验证的续约率、客户生命周期价值或稳定获客成本。

## 用户任务

制定产品上市策略，包括目标客户、价值主张、产品定位、定价、渠道、销售漏斗、试点策略和扩张门槛。

## 本轮测试要求

- 区分使用者、受益者、决策者、影响者和付款者。
- 核验客户痛点和购买触发，不能把试用意愿当成付费意愿。
- 计算或列明单位经济所需变量，不得把未验证的价格/成本当事实。
- 设计低成本付费验证和渠道实验，明确漏斗指标及归因边界。
- 正式报价、对外发布和预算超限必须停在人工审批门槛。
- 说明产品准确性样本不足时如何补测。

# 第一条视频结构建议（以「一次反常」为单位）

> 本文按新内容模型重写，替代主报告中「第一条视频的结构建议」一节。原报告 [01-douyin-fde-benchmark.md](01-douyin-fde-benchmark.md) 保留不动。
> 新模型：公开内容只分享心得与反常瞬间，**不给操作步骤**；教程是私域转化物，公开内容只用一句"想要教程私聊我"当钩子。

---

## 一、结构原则

一条视频 = 一个反常 = 一个判断。

- 不拆项目、不排第 N 集、不讲实现步骤。
- 20–40 秒，超过 40 秒就必须砍掉背景介绍，而不是砍判断。
- 落点是判断，不是笑点。"AI 好搞笑"是笑点，"它拒绝是因为它在守职责边界"是判断。

## 二、20–40 秒结构（可直接照拍）

| 时间 | 画面 | 声音/字幕 | 作用 |
| --- | --- | --- | --- |
| 0–3s | 结果画面：屏幕上那条拒绝/报错/出乎意料的输出，能看清字 | 一句话把反常说出来："我让 HR 智能体给我招个 CEO，它拒绝了。" | 反常前置，前 3 秒不解释背景 |
| 3–8s | 同一屏，手指点到关键那一行 | 补最小上下文：我在测什么、给它下了什么任务。**只给一句，不给流程** | 让观众知道"这不是段子，是真实发生" |
| 8–15s | 屏幕特写 + 你的反应（可露脸） | 说清反常点：它拒绝的具体表现是什么（拒绝执行 / 反问 / 要求授权 / 改做别的） | 把"反常"讲具体，避免观众以为是剪辑效果 |
| 15–25s | 你的脸，正对镜头 | **你的判断**：我当时的第一个念头是什么，为什么这么想 | 这一段是核心，不能省 |
| 25–33s | 屏幕/白板，给出一个可迁移的说法 | 把判断升级成观点：这说明 Agent 的边界该由谁定 / 权限该放在哪一层 | 从个案到通用，观众才愿意转 |
| 33–38s | 评论区/主页 | "你们的 Agent 有没有拒绝执行过？评论区说" | 互动钩子，收真实案例（也是下一批选题） |
| 38–40s | 字幕卡 | "想看这类边界的处理教程，私聊我" | 唯一转化位，只说一次，不放口播长篇 |

### 三条硬约束

1. **前 3 秒只给反常，不给背景。** 背景放在 3–8 秒，一句话说完。
2. **15–25 秒必须是判断，不能是吐槽。** 判断要能被反驳，才有评论区。
3. **全程不出现操作步骤。** 不点菜单、不给提示词全文、不给参数值；出现即删。

## 三、示范样本：OPC-agent 的 HR 智能体拒绝招 CEO

> 事实边界：本案例只使用作者提供的三个事实——在测试 OPC-agent 平台、让 HR 智能体招一个 CEO、被拒绝。**对话原文、拒绝理由、作者当时的判断，均留空待作者补**，本文不编造。

### 3.1 可拍骨架（约 35 秒）

| 时间 | 画面 | 台词/字幕（方括号为待作者填） |
| --- | --- | --- |
| 0–3s | OPC-agent 里 HR 智能体那条拒绝的输出，字要能看清 | "我在测 OPC-agent，让 HR 智能体给我招个 CEO——它拒绝了。" |
| 3–8s | 手指点到任务那一栏 | "任务就一句话：招一个 CEO。没有别的设定。" |
| 8–15s | 屏幕特写，停在拒绝的那句 | "它的原话是：【作者补拒绝原文】。它没有执行，也没有反问我，直接拒绝了。" |
| 15–25s | 你的脸 | "我第一反应是【作者补第一反应】。因为【作者补原因】。" |
| 25–33s | 白板写"职责边界"四个字 | "这件事真正的问题是：【作者补判断，需能一句话说清】。" |
| 33–38s | 评论区 | "你们的 Agent 拒绝执行过吗？评论区说，我挑几个下条拍。" |
| 38–40s | 字幕卡 | "这类边界怎么设，教程我放私聊了。" |

### 3.2 填这三个空之前，先过一遍判断标准

- **拒绝原文**：照抄屏幕，不改写、不润色。观众会截图对比。
- **第一反应**：写当时的真实念头，哪怕是"我以为它坏了"。
- **判断**：必须回答"这说明什么规则"，不能停在"AI 真有意思"。判断越具体越容易被反驳，被反驳才有评论。

### 3.3 这条视频不做什么

- 不解释 OPC-agent 是什么（3–8 秒一句话带过，想了解的会去私聊）。
- 不展示怎么配置 HR 智能体（那是教程，放私域）。
- 不把拒绝包装成"AI 有自我意识"（会把判断变成笑点，掉专业度）。

## 四、与旧版结构的差异

| 维度 | 旧版（结果前置 38 秒） | 新版（一次反常 35 秒） |
| --- | --- | --- |
| 单位 | 一个项目/一次交付 | 一个反常瞬间 |
| 落点 | 结果数字（3 小时 → 11 分钟） | 一个判断 |
| 步骤 | 有 12 秒录屏改造段 | 完全不出现步骤 |
| 转化 | 评论区置顶自取 | 一句"想要教程私聊我" |
| 系列 | 第 N 集连载 | 不编号，按反常类型累积 |

## 一、池子与阈值（先说数据的可信度）

| 项 | 数值 |
| --- | ---: |

| 去重后可解析的视频 | **290** |

| 点赞阈值 | **≥1 万赞**（侧栏只显示"万"级数字，低于 1 万的条目不渲染具体值） |

**三条必须先说清楚的限制：**

1. **播放量拿不到**。抖音网页版不展示播放量，本池一切"爆款"判断都基于点赞，不是播放。
2. **点赞是间接证据**。侧栏条目的文本是「时长 + 标题 + 点赞 + 作者」连在一起，我用「末尾的万级数字」取值。**53 条（种子当前条）可严格核验，其余 237 条存在把标题里的数字误读为点赞的风险**。所以：**类型分布可用，强度排序不可用**。
3. **样本天然偏向"被推荐"的视频**。侧栏是算法推荐位，进入池子本身就是一个爆款信号，但也会让池子偏向与种子相似的题材——种子里 AI/科技偏多，所以科技类被低估、生活类被高估，两个方向都有偏差。

**未达 300 条**（290 条）。差 10 条，没有用低质量条目凑数。

## 四、高频类型的共同结构

### 4.1 教程/课程（33 条，最大类）

- **开头**：给一个具体失败或误区（「AI Agent 越用越乱？」「GitHub 不是程序员专属」），第二句立刻承诺边界（「5 分钟教会你」）。
- **结果位置**：**不给成品，给"学会之后你能做什么"**。
- **情绪点**：放在中段——「你是不是也遇到过」。
- **结尾**：留「下一集讲 X」，用编号连载（第 53 集、第 67 集）。
- **关键**：这类爆款几乎全部是**系列 + 编号**，单条起量的极少。33 条里带编号的占多数。

### 4.2 萌宠 / AI 剧（19 条）

- **开头**：给角色状态，不给事件（「青梅住我家以后，我爸妈好像误会了什么」）。
- **结果位置**：**没有结果**，只有关系的推进。
- **情绪点**：每一集给一次误会/反转，30 秒内完成。
- **结尾**：下一集的钩子（「结果她爸突然回来了？」）。
- **关键**：靠**角色固定**而不是编号（虽然也标第 N 集）。

### 4.3 改装/改造（12 条）

- **开头**：给「改造前」的惨状，或直接给数字（「花 6.2W」「50 万爆改」）。
- **结果位置**：**结尾给前后对比**，不是开头。
- **情绪点**：中间的过程苦（拆、补、返工）。
- **结尾**：对比镜头 + 报价。
- **关键**：**「结果前置」在这类里只有 2 条**，绝大多数是「先惨后好」的正序。这和上一轮元素取样的结论（结果前置跨量级通用）不矛盾——那批样本是短视频（15–22 秒），这批是 2–6 分钟，**时长越长越不适合结果前置**。

### 4.4 生活记录/vlog（14 条）

- **开头**：一句状态（「本条视频主要宣布两件大事」），不铺垫。
- **结果位置**：无固定位置，靠人物关系推进。
- **情绪点**：家常细节。
- **结尾**：日常收尾，不设钩子。
- **关键**：**完全依赖角色**（藏獒、狗、家人），换人即失效。

## 五、迁移性判断：哪些能搬到「用 agent 做东西 + 真人出镜」

| 类型 | 能不能迁移 | 为什么 |
| --- | --- | --- |
| 教程/课程 | **部分能** | 结构可借（具体误区 → 边界承诺 → 下一集），但**不能给步骤**。你的版本应该是「具体反常 → 我的判断 → 下一集试什么」，把"教会你"换成"我判断错了/对了" |
| 改装/改造 | **能，最匹配** | 「改造前惨状 → 过程返工 → 前后对比」正好对应「流程原状 → 智能体出问题 → 跑通后的数字」。且这类允许 2–6 分钟，适合录屏 |
| 挑战/实验 | **能** | 时间盒 + 可验证数字（「14 天把 3 小时压到 10 分钟」），天然适配 agent 项目 |
| 生活记录/vlog | **能借结构，不能借内核** | 它的爆款靠角色关系（狗、孩子、家人），你没有角色；但「一句状态开场 + 家常细节」的写法可以用 |
| 萌宠/AI 剧 | **不能** | 靠角色和剧情推进，观众消费的是关系；且这类账号需求信号为 0（前轮 3 个 AI 剧样本 L1/L2 全 0） |
| 剧情/短剧 | **不能** | 需要演技/剧本/AI 生成，与"真人出镜做东西"冲突 |
| 音乐/舞蹈 | **不能** | 才艺门槛，且不可替代 |
| 影视解说 | **不能** | 无真人、无原创素材，与 FDE 人设零关联 |
| 美食 | **不能** | 品类的信任来自"好吃"，不是"能做系统" |
| 知识科普 | **谨慎** | 容易滑成"AI 科普"，你明确不做；但「反常识结论 + 证据」的内核可以借 |
| 测评/开箱 | **不能** | 需要选品与供应链，且测评号的粉丝质量在前轮已证偏低 |

### 一句话总结

**能搬的是「改造」和「教程」的结构，不能搬的是「角色」和「才艺」。** 你的题材唯一能同时拿到"过程感"和"真人"的位置，是「改造型 + 判断型」的交叉：把智能体当成一个需要被改造的对象，前后对比给数字，过程中给反常，结尾给判断而不是步骤。

## 六、这份池子不能证明什么

1. **不能证明哪一类"最容易爆"**：点赞值有 237 条未严格校验，且播放量拿不到，任何"X 类最强"的结论都不成立。分布只能说明**池子里有多少**，不能说明**哪类更容易进池子**。
2. **不能证明「反常 + 结果前置」有效**：290 条里这两个手法合计 4.5%，样本量不足以支撑或否定。
3. **AI/科技类被系统性低估**：侧栏推荐稀释，6 条不代表全站。
4. **"其他"占 30.3%**：说明关键词分类法对混合型标题失效，这部分没有进入任何结构分析。

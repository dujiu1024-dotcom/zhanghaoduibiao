# 你要做的事

三件都定了。只剩一个由决策一衍生出来的冲突：闲鱼 199 算不算例外。

## 1. 报价：先不对外说（已定）

- 对外话术、私信模板、闲鱼文案、对外介绍：不出现 8,000、199 或任何固定价。
- 被问价统一回：“先聊需求，再给方案和价。”
- 内部保留 8,000 作预估，必须标“未对外”。
- 遗留冲突：闲鱼挂单必须填价格。199 是当前挂单价，和“对外不出现任何死数”直接冲突。

## 2. 案例：前公司、前客户都能讲，可以点名（已定）

- 可以讲项目，可以点名公司、客户。
- 客户内部数据、单价、未公开的具体数字，不写具体数。

## 3. 三本书：不买（已定）

- Story、金字塔原理、Nagle 定价，三本都不买。
- 改用公开替代材料：P0 目录 17 份，全部仅参考，可引原文 0 份。
- 这三格只能转述，不能引原句；写稿时标“公开替代材料·仅参考”。

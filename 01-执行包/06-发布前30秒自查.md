# 发布前 30 秒自查清单

用法：贴在手边。每条视频、每条私信、每张报价单发之前扫一遍，命中任何一条就停下来改。
三条铁律：**没有承诺、没有头衔、没有来路不明的数字。**

---

## 一、一条视频（20 秒）

先扫文字，再听声音。

| 扫什么 | 命中的样子 | 怎么改 |
| --- | --- | --- |
| ① 效果承诺 | "保证""一定行""包落地""省一半""三天搞定""再也不用管" | 换成"我这边跑出来是X，样本是几个" |
| ② 极限词 | 最、第一、唯一、顶级、天花板、最低价、全网 | 直接删；说具体差异点 |
| ③ 头衔背书 | "官方认证""官方推荐""行业领先""专家""大厂都在用" | 说清谁发的证／说具体做过什么 |
| ④ 无出处数字 | "提升 300%""服务过 200 家""月入五万" | 要么给出处，要么删 |
| ⑤ 站外导流 | 口播里念"微信""加V""看主页加我" | 改"私信我""评论区置顶" |
| ⑥ 交换式互动 | "点赞过百就出下期""扣1发你" | 改"想看的说一声""置顶自取" |
| ⑦ 医疗功效 | 治好、治疗、改善XX病、降三高 | 改个人经历描述，涉病直接不提 |

**声音之外还要看三处**：封面、标题、字幕。这三处最容易补台词里没有的承诺。

最后 5 秒：**有没有一句"我希望你记住的是我这个人"，而不是"我的东西多便宜"。** 没有就补。

## 二、一条私信（5 秒）

| 扫什么 | 命中的样子 | 怎么改 |
| --- | --- | --- |
| ① 时限有没有起算点 | "14 天做完""48 小时回你" | 加"从你确认范围那天算" |
| ② 范围有没有写死 | "顺便帮你把 X 也弄了" | 写"只含 X，Y 另算" |
| ③ 有没有"包/保证/百分百" | 三个词任一出现 | 删，换成"我做到的""按合同" |
| ④ 有没有造紧迫感 | "这周不订就没了" | 只在排期真满时说；否则说"随时能开工" |
| ⑤ 有没有贬低同行 | "别家都是坑""谁保证谁在骗你" | 只讲自己做什么，不评价别人 |
| ⑥ 首条消息有没有问预算 | "你预算多少" | 先问场景，预算第三轮再问 |

## 三、一张报价单（5 秒）

| 扫什么 | 命中的样子 | 怎么改 |
| --- | --- | --- |
| ① 价格表述 | "原价 9999，现价 999"（原价不存在） | 原价必须真实存在过；否则只写现价 |
| ② 交付边界 | 只写"做一个系统" | 写清交付物、轮次、不含项 |
| ③ 修改次数 | "改到满意" | 写"两轮，改方向另算" |
| ④ 退款条件 | "不满意全退" | 写"哪几种情况退、几天内、谁判定" |
| ⑤ 效果承诺 | "预计节省 50% 人力" | 改成"按你现在的量，理论上可减少X小时/周"，并注明是估算 |
| ⑥ 客户信息 | 截图带客户名、账号、订单号 | 截图脱敏；**公司名、项目名可直接点名**（2026-11-15 用户拍定）；真人姓名、手机号、头像、客户后台截图不出现 |
| ⑦ 第三方标识 | 截图里有别家 logo、平台水印 | 打码或裁掉 |

## 四、一句话版本（记不住上面就记这个）

> **不承诺效果，不给自己封头衔，不写没有出处的数字；价格写清范围，退款写清条件，客户写清授权。**

## 五、命中后的处理顺序

1. 能删就删（极限词、头衔）。
2. 删了信息不够，就换成"具体事实"（我做过什么、多久、几个人）。
3. 事实也拿不出来，就换成"模糊但不假"的说法（几个、一些、大概）。
4. 三步都做不到，这条内容先别发。

依据：`04-知识底座/knowledge/sources/口播替换表.md` 32 条 + `fulltext/official/douyin-lifexue-jueduihua-yongyu-xize.txt` 99 词 + `fulltext/law/guanggao-fa.txt` 第八、九、十一、十三、十七、二十八条。

## 六、扫描器误报：加白名单，不改文字

`check_copy.py` 是词表匹配，会把合规的否定句、引用原文、生产说明判成硬禁。**遇到误报，正确做法是把位置加进白名单，不是改文字。**

1. 判定顺序：先确认这句是不是真会发出去。会发出去（脚本、闲鱼正文、主页简介）→ 只能改到确实不违规；不会发出去（修订记录里引用的旧文案、自查清单、禁止项说明）→ 不动文字，走白名单。
2. 加白名单：在 `01-执行包/check_copy_whitelist.json` 的 `entries` 里加一条，四个字段必填——`file`（文件名）、`phrase`（命中行里必须包含的原文片段）、`reason`（为什么是误报）、`added`（日期）。
3. 理由写法：必须说明"为什么不是违规"，例如"否定句，明确不承诺效果"；不许写"误报""没关系"这类空话。
4. 不许为了过扫描改写三类文字：法规与平台公约原文、引用他人原话、引用的自家旧文案。
5. 白名单输出会单独列在扫描结果里（"白名单豁免 N 处"），不并进硬禁数；硬禁数仍须为 0 才许发。
6. 复核：每月看一次白名单，条目超过 10 条或出现"为了省事加进去"的，回头改规则而不是继续加。

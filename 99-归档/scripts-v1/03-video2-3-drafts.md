# 三条共用

## 1. 结尾转化句（三条同一条，一字不改）

> 你要是也在让电脑替你记事、干活，又怕它乱来，私信我，坑我踩过了。

- 不喊「关注」「点赞」「领取」，不报课程名，不放价格。
- 落点在「我踩过，可以告诉你」，不在「我有东西卖给你」。

## 2. 简介三行

| 行 | 内容 | 作用 |
|---|---|---|
| 第一行 | 一个人开公司，自己写工具，自己收拾烂摊子。 | 身份 |
| 第二行 | 让电脑自己开软件、打字、记事；翻车了也照原样记下来。 | 能力 |
| 第三行 | 在做同类尝试，或者想把重复活交给电脑的，私信聊。 | 承接 |

## 3. 置顶评论第一句

> 补一句：拦住它的那条规矩，是我自己写的，到现在还没删——你们说该留吗？

- 只一句，先认领「规矩是我定的」，再把判断交给评论区。
- 不解释技术细节，不在评论里重复视频内容。

# FDE 抖音账号 · 工具清单（十一环节）

适用对象：一个人，FDE 方向（把业务需求翻成能跑的 AI 系统），抖音起号，靠内容接单。工具层从零开始。
采集日期：2026-11-14。价格单位：人民币元。价格为当日页面抓取，平台促销、内购价、淘宝成交价都会变，下单前以页面为准。

**这套工具只服务一件事：让你在视频里"真的把东西跑起来"。** 不是把你包装成工具测评号，也不是让你看起来专业。观众信你，是因为画面里那个程序真的跑通了。

## 0. 先做这五件事

1. 今天装完 0 元套（见第 12 节 A），其他一律不买。
2. 第一条视频就按"口播 40 秒 + 录屏 40 秒"的结构拍，不要等设备。
3. 麦克风是唯一值得先花钱的东西。预算 100 元就买有线领夹，预算 1000 元买无线麦。
4. 录屏参数照第 4 节的 8 项检查设，比换录屏软件有用十倍。
5. 接单链路先用免费件跑通：抖音私信 → 微信 → 飞书报价单 → 腾讯电子签个人版 → 个人收款 → 自然人代开。

三条结论：

- **必须花钱的只有两样**：麦克风、手机支架，合计 100–250 元；补光灯只在晚上录时买。软件全部有免费替代。
- **录屏不需要买软件**。OBS + ZoomIt／KeyCastr + 剪映，0 元，效果不输 200 美元的 ScreenFlow。
- **第三方数据平台、千川、多平台分发工具，第一条爆款之前全部不要买**。它们放大的是已有结果，不是帮你做出结果。

**本环节推荐：OBS 主录 + ZoomIt（Win）／KeyCastr（Mac）+ 剪映后期。**

理由：

- OBS 免费、无水印、没有时长限制，能在一个画面里同时放"代码窗口 + 人脸小窗 + 麦克风"，一次拍完不用对轨。这正是 FDE 内容需要的形式：观众要同时看到"你在说"和"程序在跑"。
- ScreenFlow 和 Camtasia 贵在"录完能直接剪"。但你已经用剪映了，这部分钱是重复支付。
- 真正决定"录得清楚"的是下面 8 项检查，不是软件。

### 录屏前 8 项检查（照这个设）

| # | 检查项 | 具体做法 |
|---:|---|---|
| 1 | 分辨率 | 录制画布 1920×1080、30fps。不要录 4K 全屏，字会被压小 |
| 2 | 录制区域 | 只框代码／终端窗口，不录整个桌面和 Dock |
| 3 | 字号 | 编辑器 16–20 号，终端 18–24 号，深色主题，关掉 minimap |
| 4 | 鼠标可见 | 系统设置里把指针调大；点击时停 0.5 秒再动 |
| 5 | 局部放大 | 关键一行代码用 ZoomIt 放大到 2 倍，讲完缩回，不要全程放大 |
| 6 | 隐私 | 关通知、关微信、关浏览器标签，遮掉密钥、客户名、内网地址 |
| 7 | 分段 | 一段只讲一个动作，30–90 秒。错了整段重录，不做长镜头硬剪 |
| 8 | 回看 | 录完先在手机小屏看一遍，字看不清就重录，不要指望后期放大 |

**补充（Mac）**：系统自带 `Cmd+Shift+5` 就能录区域，适合临时补镜头；QuickTime 适合录单窗口。**补充（Windows）**：`Win+G` 呼出 Xbox Game Bar，适合临时录；正式录制还是用 OBS，因为要同时收人脸和麦克风。

**一条内容的标准录屏结构**（40–60 秒）：

1. 先给结果画面 3 秒（"这是已经跑起来的系统"）。
2. 切到起点（"现在什么都没有"）。
3. 只演示一个关键动作，配一句人话解释（"我把这张表丢给它"）。
4. 回到结果，停 2 秒不说话，让观众看清。
5. 最后一句给下一步（"这套东西我做了 3 天，下面讲哪一步最容易崩"）。

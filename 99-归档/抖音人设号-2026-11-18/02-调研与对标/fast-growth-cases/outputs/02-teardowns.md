## 二、六个关键样本拆解

### 2.1 柱子奇遇记｜69.5 万 / 47 条｜三信号 3/3

- **起量条**：257.7 万赞，3:43，标题「少年，向前走，前路漫漫亦灿灿」。
- **形式**：实拍 + 作者出镜，画面是给一个农村孩子搭舞蹈室、让他上台。
- **系列结构**：单事件推进，没有编号，靠人物关系连载（嘉睿一家）。
- **评论区**（原话）：孩子母亲留言「谢谢柱子博主给他弄的舞蹈室，还有给了他上台表演的机会……我们家条件一般，三个孩子，我能力有限，但只要他想跳，我尽我最大的能力让他跳」（1.9 万赞，作者赞过）；作者回「不客气姐您是一位很了不起的母亲」。
- **需求分级**：L4 100%。没有一条问「怎么做」或「多少钱」。
- **承接**：简介只有「一个生活的采撷者，我相信记录本身，就是对美好最深的回应」，**无任何入口**。典型「流量未承接」。
- **对 FDE 的价值**：他的涨粉机制不是内容技巧，是**代际共情 + 真实人物 + 作者下场**。可借的是「作者必须进入画面并承担关系」，不可借的是「公益型事件」——你没有一个农村孩子。

### 2.2 海狗一条｜117.6 万 / 77 条｜三信号 2/3

- **起量条**：79.5 万赞，4:23，「一条不知道是聪明还是笨的狗，学什么，海狗有自己的想法」。
- **形式**：实拍宠物 + **固定旁白人设**（不出镜，但声音和视角固定，自称「仆人」）。
- **系列结构**：无编号，固定角色「海狗」，每集一个行为观察。
- **评论区**：「这才是正常狗狗的表现，没有过度驯化，有些为了博流量把狗狗驯化的比人都聪明了，但是海狗是快乐的」（6.8 万赞）；「奇迹，海狗仆人居然做到了半月更」（1.3 万赞）。L3 = 1（驯化讨论），L4 = 2。
- **承接**：无。
- **价值**：**「固定视角 + 固定称呼」可以在不露脸的情况下做人设**。「海狗仆人」这个自称让观众有了称呼你的方式——这是三信号里最便宜的一条。

### 2.3 拉小提琴的王主任｜730.4 万 / 645 条｜三信号 3/3

- **起量条**：161.4 万赞，1:18，「当你在 2026 年再次听到这首歌（第 13 集）」。
- **形式**：实拍课堂，固定学生角色（pe姐、转姐），作者是「王主任」。
- **系列结构**：有编号（第 13 集），有固定角色，靠「第 N 集」追更。
- **评论区**：作者置顶式回复「左边pe姐@Dazzling，右边转姐@恩恩恩恩恩，两个人今年高二」（20.7 万赞）；「小时候我奶经常唱这首歌哄我睡觉」（43 万赞）。
- **承接**：简介「图:tktk8088 商务作：ctian1979」【可见】——**商务和微信都明写**。
- **价值**：**编号 + 固定角色 + 明确商务入口**，这是成熟人设号的标准配置。但 645 条才 730 万，说明它是长期积累，不是单条起量。

### 2.4 天才海啸｜10.7 万 / 84 条｜三信号 1/3｜「爆的是视频不是人」

- **起量条**：132.3 万赞，2:30，「在北大听到一节想流泪的课」。
- **关键数据**：这条占账号总获赞（276.7 万）的 **47.8%**——**一条视频撑起半个号**。
- **评论区**：「@抖音求真 真的吗？」（1.0 万赞）；「高敏感的人总是能察觉到身边人微妙的恶意」（2.3 万赞）；作者回「老师说：发展的最好的小孩和发展最不好的小孩，都是高敏感的小孩」。
- **需求分级**：L4 全部，L3 仅 1 条（求证）。
- **承接**：简介挂 @Tsusu（矩阵号），无商务入口。
- **结论**：这是「爆款不爆人」的标准样本。视频靠「北大 + 想流泪」的情境反差起量，观众记住的是课，不是作者。**对做人设号的参考价值要打折**：它证明 10 万粉可以由一条视频带来，但不证明人能留住。

### 2.5 青提夏（AI 自制剧）｜7.4 万 / 28 条｜粉/条 2,643

- **起量条**：2.5 万赞，12:37，「自制美剧《SecretCrush》1–5 合集纯享版，一次看爽」。
- **形式**：AI 生成剧集，纯搬运式合集（1–5 集剪成一条）。
- **评论区**：「好看，一次性看爽了」（31）；「怎么办，直接爱上了」（90）；「谁敢做中国高中剧」（7）；「耍我，我以为出后续了」（405）→ 作者回「说了是合集呀」（91）。
- **需求分级**：L1 0 / L2 0 / L3 0 / L4 全部。
- **承接**：简介「即梦优创｜小云雀优创｜会持续更新，纯原创制作，禁止搬运」——**这是平台/工具的合作署名，不是给观众的入口**。
- **结论**：28 条做到 7.4 万，涨粉效率是这批里最高的之一（2,643 粉/条）。但评论区 100% 是剧情消费，**没有一个人问怎么做、多少钱**。

### 2.6 赵小五剪辑日记｜31.9 万 / 52 条｜粉/条 6,135

- **起量条**：8,466 赞，7:19，「到底是剪辑技巧重要还是一个好的素材更重要」。
- **形式**：口播 + 录屏对比（同一文案拍两版）。
- **评论区**：「你应该，发两条，看看哪个数据好，你说的这些对普通用户来说根本不重要」（1,167 赞）；「新手这个很像剪映的智能包装一键做的」（329 赞）。
- **需求分级**：L3 为主（同行质疑/拆台），L4 少量。
- **承接**：简介「：ZXW55885 学习要素材交作业随便」【可见】——**微信号直接挂在简介**。
- **结论**：这是 15 个里唯一「教学 + 明确微信承接」的组合，且 52 条做到 31.9 万。它的涨粉靠「反常识判断」（素材 > 技巧），不是靠步骤——**和你要做的「给判断不给步骤」最接近**。

## 三、15 个样本的共同点（不是巧合）

1. **L1/L2 = 0**。无论 1,159 万粉还是 10.7 万粉，评论区都不出现「能不能帮我做」「教程在哪」。需求信号不随粉丝量增长——**粉丝量不产生需求信号，内容类型才产生**。
2. **承接入口和粉丝量无关，和「这人有没有生意」有关**。王主任（730 万）写商务+微信，BBoxer（203 万）写工作微信，赵小五（31.9 万）写微信；柱子（69.5 万）、海狗（117.6 万）、蛇小男（295.6 万）什么都不写。**写不写入口是选择，不是能力**。
3. **「无编号 + 固定角色」比「第 N 集」更常见**。15 个里只有王主任（第 13 集）和星白漫（分集追更）用了集数；其余靠固定人物/固定视角连载。这和你「一个智能体反复试」的思路一致——**靠角色连续性，不靠集数编号**。
4. **时长两极**：情绪型 1:18–4:50，知识型 4:54–10:06。15 个里没有 20–40 秒的样本——**这个时长在这批人设号里是空白**，既没有成功样本，也没有失败样本。

## 1. 方案 A · 一人交付

| 项 | 内容 |
| --- | --- |
| 昵称 | **一人交付**（4 字） |
| 简介（27 字） | 帮不懂技术的人，把重复的活做成能跑的工具。坑我自己踩。 |
| 头像 | **实拍**。半身、侧身 45°、面前是正在用的电脑或写满字的纸，自然光，不磨皮、不虚化背景、不摆拍。要让人看出"这是在干活的地方"，不是办公室写真。 |
| 押什么 | **在场感**。市面上讲 AI 的人多，真到现场把东西做出来的人少，押"这个人真的在干"。 |
| 适合的内容路线 | 交付日记：一次交付里发生的事、被自己的规矩拦下、返工、验收。第一条正是这个形态。 |
| 放弃了什么 | 搜索词流量（昵称里没有 AI、工具这类被搜的词）；泛 AI 科普的涨粉速度；靠单条爆款起号。 |
| 与第一条的咬合 | 第一条讲"我在自己项目里被规矩拦下"，正好是交付日记的第一篇。 |

风险与提醒：
- 昵称不带品类词，前 15 条只能靠内容本身把人留住，涨粉会慢于带关键词的号。这是选的代价，不是执行失误。
- 头像必须实拍。用生成图、用别人的工作照，都踩"人设不实"（自律公约第 23、35 条）。

## 2. 方案 B · 交付留痕

| 项 | 内容 |
| --- | --- |
| 昵称 | **交付留痕**（4 字） |
| 简介（24 字） | 做过什么就拍什么。记录、报错、验收单，都能对上。 |
| 头像 | **实拍物件特写**，不出现人脸：一段报错、一张验收单、一块屏幕的局部。整张图只有一处焦点，背景压暗。属"实拍＋符号化"，不是纯图形。 |
| 押什么 | **证据密度**。别人能编一个翻车故事，编不出能顺着核对的记录链，押"我说的每条都能查"。 |
| 适合的内容路线 | 案例拆解：一条记录分三层讲；验收对照；同一件事做前做后。每条视频至少一个可截图的原件。 |
| 放弃了什么 | 人格温度。头像不露脸，视频里真人句只剩 3 句下限，观众记住的是"这个号有料"，不是"这个人"。按大前提这是明确代价：会削弱「我这个人」。 |
| 与第一条的咬合 | 成立。第一条的证据是 `summary.md` 的原文与步骤图，正好是"留痕"的样子。 |

风险与提醒：
- 素材门槛高：每条都要有硬原件，没有就拍不了。产能会被素材卡住，不能靠"讲一个观点"凑数。
- 不露脸的号在抖音涨粉效率普遍低于露脸号，这一条属【偏好】，没有本账号数据；选它就接受慢。

## 3. 方案 C · 不画饼的AI落地

| 项 | 内容 |
| --- | --- |
| 昵称 | **不画饼的AI落地**（9 字） |
| 简介（22 字） | 不接画饼的活。只拍真做过、能验收的 AI 项目。 |
| 头像 | **纯图形符号**，无真人：白底、黑字方形印章样式，四个字"不画饼"，字压边、留白多。不做渐变、不加图标。 |
| 押什么 | **立场**。押"敢说哪些活不能接"，用态度换记忆点和转发。 |
| 适合的内容路线 | 拆穿与对照：同行报价单拆开看、客户提的离谱需求、我拒掉的三类活。情绪浓度高于方案 A、B。 |
| 放弃了什么 | 保守客户的好感（有老板不喜欢看人拆同行）；同行对线会带来无效流量；最容易滑成吐槽号，一滑就踩"不做纯娱乐号"这条底线。 |
| 与第一条的咬合 | 弱。第一条是"我被自己的规矩拦下"，偏自我约束，不是拆穿别人。真要选 C，第一条得换成"我拒过的一单"。 |

风险与提醒：
- 立场型号的评论里同行占比通常偏高，按假设台账 #11 的口径，同行超过 50% 说明没打到老板。
- 昵称里"不画饼"是态度词，不是品类词，别人搜不到；靠推荐流。

## 4. 三套真不一样在哪

| 维度 | A 一人交付 | B 交付留痕 | C 不画饼的AI落地 |
| --- | --- | --- | --- |
| 观众 3 秒后记住 | 这个人在干活 | 这个号有原件 | 这个人敢说话 |
| 涨粉靠 | 追更关系＋现场感 | 单条信息密度 | 情绪共识与转发 |
| 接单靠 | "他真做过，找他问问" | "他能验收，靠谱" | "他懂行，不会坑我" |
| 头像 | 真人实拍 | 物件实拍，不露脸 | 纯图形，不露脸 |
| 素材门槛 | 中（有记录即可） | 高（每条要原件） | 低（有观点即可） |
| 每周产能 | 3 条可行 | 2–3 条，受素材限制 | 3–5 条，最省力 |
| 第一条是否成立 | 成立 | 成立 | 不成立，要换题 |
| 主要风险 | 涨粉慢 | 人设变淡 | 滑成吐槽号、同行占比高 |

## 5. 选哪套

**建议选 A。**

三条理由：
1. 【偏好·宪法级】一切产出服务于突出「我这个人」，A 是唯一把"人"放在第一眼的方案（`AGENTS.md` 大前提）。
2. 【有依据的推断】第一条素材本身就是"我在自己项目里被拦下"，A 的路线和现有素材同形，不用为选方案改选题；B 也成立，但要接受人设变淡；C 要重写第一条。
3. 【有依据的推断】C 的短期涨粉可能更快，但它把"敢说话"放在了"真做过"前面，与"绝对不能稀释真能落地"的约束相反。推断链 2 步，无本账号数据。

**选 A 放弃了什么**：昵称里的搜索关键词、更快的涨粉曲线、以及"靠一条爆款起号"的赌法。要换回来，只能靠用户重新拍板。

## 6. 换套的触发线与手续

- 30 天内不换套。前 5 条只许调措辞（简介、封面、首句三种说法），方向不动。
- 换套要用户拍板，不由数据自动触发（人-05 口号锁定）。
- 出现下列信号时，先把信号记下来，报给用户，不自行换：
  - 连续 5 条评论只在问"这是什么工具/怎么做的"，没有一条问"你那边能不能做" → 观众记住的是工具，不是人。
  - 连续 3 条评论只有"哈哈/厉害" → 按止损线换题材，不换套。
  - 主页访问高、关注低 → 是封面与开头的问题，不是方案的问题。

## 7. 合规自检（三套通用，发布前逐条过）

- 昵称、简介里没有微信、手机号、图形码、网址、邮箱，谐音也不许（自律公约第 36 条）。
- 没有广告法第九条明列的三个极限词，也没有"最、首个、独家、顶级、全网"这类绝对化表述（广告法第九条＋平台细则）。
- 没有粉丝数、客户数、省钱比例这类拿不出出处的数字（广告法第十一条）。
- 没有"官方、认证、合作方"这类没有的资质（自律公约第 37 条）。
- 没有价格（199 只出现在闲鱼）。
- 头像不用生成图、不用他人照片、不用客户后台截图。

## 8. 还缺什么（只有你能给）

1. **出镜条件**：能不能稳定露脸、拍摄地点在哪。三套里 A、B 都要求真人出镜，C 也要 3 句真人。
2. **昵称是否被占用**：三个昵称都要在抖音现场搜一次，重名就换字，不能加数字凑。
3. **前公司、前客户的具体名称**：简介里不需要，但"点名版"的文案要用，你确认了才能写进去。
4. **头像素材**：A 需要一张你正在干活的实拍；B 需要一张可公开的验收单或记录截图（打码后）。

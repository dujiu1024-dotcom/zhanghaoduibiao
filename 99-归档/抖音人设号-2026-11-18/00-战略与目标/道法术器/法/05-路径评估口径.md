### A. 先分账：评估的是名气还是生意

#### 评-01 涨粉与接单分两本账，不合并

1. **知识**：〔本库·方法文档〕「这条链是**串联电路，不是并联。断一层，后面全黑**。」〔本库·方法文档〕「北极星是'有效私信数'，不是粉丝数。」
2. **出处**：〔本库·方法文档〕`00-操盘主干.md` 层间传导表；`增长理论-AARRR到复购.md` §1。
3. **适用情形**：评估任何一条路径前。
4. **动作**：每条路分别记两栏：名气档（播放/粉丝）、生意档（有效私信/报价/成单）；两栏不合并成一个总分。
5. **代价**：人力：库内无；时长：库内无；现金：库内无；风险：合并后会用粉丝数掩盖没有成交
6. **边界**：两本账不是永远分开；第 3 层"被信任"同时服务两者，但指标仍分开记。

#### 评-02 先问这条路提升的是播放还是有效私信

1. **知识**：〔本库·方法文档〕「把'**有效私信数**'定为北极星，而不是粉丝数。每周记一次私信里出现'多少钱/能不能做'的条数。」
2. **出处**：〔本库·方法文档〕`增长理论-AARRR到复购.md` §1。
3. **适用情形**：一条路跑了两周后。
4. **动作**：给每条路标一个主指标：只提播放的标"名气档"，能提有效私信的标"生意档"；不能提有效私信的，不写成"能接单"。
5. **代价**：人力：每周记 1 次；时长：每周；现金：0；风险：早期有效私信可能为 0，容易误判
6. **边界**：有效私信需人工判定，不能靠平台统计；早期 0 私信不能直接否定内容（项目硬账阶段）。

#### 评-03 阶段判断看私信问价比例，不看粉丝数

1. **知识**：〔本库·方法文档〕「判断当前阶段只看一个指标：**私信里问价的比例**。0 → 识别期；开始出现 → 信任期。」「粉丝可以买，问价不能。」
2. **出处**：〔本库·方法文档〕`L2-战略-IP操盘.md` §二、§五.5。
3. **适用情形**：每周/每月阶段复盘。
4. **动作**：数私信里"多少钱/能不能做"的条数，按"0 / 开始出现"两档判阶段；粉丝数只作参考。
5. **代价**：人力：每周 10 分钟；时长：每周 10 分钟；现金：0；风险：阈值只有两档，中间态无法细分
6. **边界**：问价比例的中间阈值库内无；不能拿粉丝数替代阶段判断。

### B. 跟自己比：基线怎么定

#### 评-04 只跟自己上周/同类中位数比，不跟行业平均比

1. **知识**：〔本库·方法文档〕「**替代测法**：算每段**相对上周的变化**，不跟'行业平均'比——行业数据全部**未获取**。」「不追'行业转化率'，只比自己上周。」
2. **出处**：〔本库·方法文档〕`L1-内容营销漏斗.md` §四、§五.4。
3. **适用情形**：周复盘。
4. **动作**：每条指标只跟"自己上周"或"自己同类同长度中位数"比；不引用行业平均值。
5. **代价**：人力：每周对一次数；时长：每周；现金：0；风险：没有历史基线时第一周无法判断
6. **边界**：跨时长、跨题材不可比；行业基准全部未获取（§四）。

#### 评-05 完播异常线：低于自己同类中位数 20%

1. **知识**：〔本库·方法文档〕完播异常按"低于自己同类同长度中位数 20%"判；本库不采用任何行业及格线。
2. **出处**：〔本库·方法文档〕`L1-完播口径.md` §三、§五。
3. **适用情形**：单条发布 48 小时后。
4. **动作**：先建自己同类同长度的中位数，低于 20% 才判异常；不拿 30%/50% 当及格线。
5. **代价**：人力：建表；时长：发布 48 小时后；现金：0；风险：样本少时中位数不稳
6. **边界**：样本 <5 条时中位数不可用，只能记录；与涨-25 的 50% 粗筛冲突，**未裁决**（见涨-25）。

#### 评-06 48 小时数据定型，过后不再追

1. **知识**：〔本库·方法文档〕单条数据以发布后 48 小时为复盘窗口；过后不再用这条的短期数据改结论。
2. **出处**：〔本库·方法文档〕`制作-02-单条视频复盘方法.md` §一。
3. **适用情形**：每条复盘。
4. **动作**：发布后 48 小时记一次四数，之后不再追这条的播放变化。
5. **代价**：人力：10 分钟；时长：48 小时；现金：0；风险：长尾流量可能被忽略
6. **边界**：48 小时是复盘窗口，不是平台数据截止；长尾爆款需单独标记，不能混进常规对照。

#### 评-07 复盘只看四个数：5 秒完播 / 完播率 / 评论 / 私信

1. **知识**：〔本库·方法文档〕复盘只看四个数：5 秒完播、完播率、评论数、私信数；其余数据不进入单条判定。
2. **出处**：〔本库·方法文档〕`制作-02-单条视频复盘方法.md` §五.1。
3. **适用情形**：单条复盘。
4. **动作**：每条只填这四列；点赞/收藏只作参考，不进入判定。
5. **代价**：人力：10 分钟；时长：每条；现金：0；风险：漏掉收藏/转发等长尾信号
6. **边界**：四个数是单条判定口径，不是账号总账；账号总账另看有效私信与成单。

#### 评-08 判定顺序：开头 → 观点 → 人设

1. **知识**：〔本库·方法文档〕「判定顺序固定：先看开头（2 秒），再看观点（评论），最后看人设（主页访问）。」
2. **出处**：〔本库·方法文档〕`制作-02-单条视频复盘方法.md` §五.3。
3. **适用情形**：单条数据异常时。
4. **动作**：按顺序排查，前一项没排除不跳到下一项；只改命中的那一项。
5. **代价**：人力：10 分钟；时长：每条；现金：0；风险：顺序错了会把人设问题当选题问题
6. **边界**：三项都正常但数据低，可能是分发/时段问题，库内无判定标准。

#### 评-09 同一选题两次不成即弃

1. **知识**：〔本库·方法文档〕「同一选题最多试两次（两种开头），两次都低就判死，不第三次。」
2. **出处**：〔本库·方法文档〕`制作-02-单条视频复盘方法.md` §四。
3. **适用情形**：选题复盘。
4. **动作**：同选题只换两种开头各发一次；两次都低于自己中位数，停止该选题。
5. **代价**：人力：库内无；时长：两次；现金：库内无；风险：播放几百时差异可能是噪声
6. **边界**：若第二次已明显改善，可按"结构问题"重拍；样本 <5 条时慎用"判死"。

### C. 归因四问：结论能不能说

#### 评-10 前 15 条不做 A/B，只做每 5 条类型复盘

1. **知识**：〔本库·方法文档〕「前 15 条**不做 A/B**，只做'每 5 条复盘一次类型配比'。等单条稳定过 1 万播放，再谈对照实验。」
2. **出处**：〔本库·方法文档〕`增长理论-AARRR到复购.md` §4。
3. **适用情形**：新号前 15 条。
4. **动作**：每 5 条填一次类型配比表，不做显著性判断、不宣布"A 比 B 好"。
5. **代价**：人力：每 5 条 20 分钟；时长：每 5 条；现金：0；风险：几百播放无统计功效
6. **边界**：单条稳定过万后再谈对照；所需样本量库内无。

#### 评-11 单条稳定过万再谈对照实验

1. **知识**：〔本库·方法文档〕「等单条稳定过 1 万播放，再谈对照实验。」
2. **出处**：〔本库·方法文档〕`增长理论-AARRR到复购.md` §4。
3. **适用情形**：账号进入稳定播放期。
4. **动作**：连续多条稳定过万后，才按"每组 3 条、只改一个变量"做对照。
5. **代价**：人力：库内无；时长：库内无；现金：库内无；风险：未到阈值就做实验，结论是噪声
6. **边界**：1 万是库内门槛，不是平台标准；不同题材门槛可能不同（库内无）。

#### 评-12 分母是谁？换抽样框还成立吗？

1. **知识**：〔本库·方法文档〕「样本只能代表它的抽样框，不能代表总体。」「自查句：这个数字的分母是谁？换一个抽样框还成立吗？」
2. **出处**：〔本库·方法文档〕`抽样与归因的边界.md` §一。
3. **适用情形**：引用任何比例/排名前。
4. **动作**：写结论时同时写清分母（哪个池子、多少样本、什么筛选条件）；换框不成立就降级为"样本内观察"。
5. **代价**：人力：5 分钟；时长：5 分钟；现金：0；风险：分母错，后面所有比例作废
6. **边界**：抽样框偏向成熟账号/机构号时，不能外推到新号/小号（同文案例）。

#### 评-13 "没观察到"不等于"不存在"

1. **知识**：〔本库·方法文档〕「样本里 0 例，只能说明**这个样本里没有**，不能说明总体没有。」「自查句：这是'没看到'还是'测到没有'？」
2. **出处**：〔本库·方法文档〕`抽样与归因的边界.md` §二。
3. **适用情形**：样本里出现 0 例时。
4. **动作**：写"在这 N 个样本的可见范围内未观察到"，不写"没有/不存在"；并注明样本没覆盖哪些位置。
5. **代价**：人力：5 分钟；时长：5 分钟；现金：0；风险：把 0 例当规律，会做错方向
6. **边界**：样本覆盖了反例可能出现的位置，才能谨慎说"倾向于没有"；仍不能证明总体为 0。

#### 评-14 自变量在样本里分布开了吗？有对照组吗？

1. **知识**：〔本库·方法文档〕「要断言 A 随 B 变化，样本必须在 B 上**分布开**。」「如果样本里没有日更的号，就只能说'样本里没有日更的人设号'，不能说日更不好。」
2. **出处**：〔本库·方法文档〕`抽样与归因的边界.md` §三。
3. **适用情形**：想说"A 导致 B"时。
4. **动作**：先列自变量的最小值/最大值/中位数和对照组；分布不开就只写描述，不写因果。
5. **代价**：人力：10 分钟；时长：10 分钟；现金：0；风险：没有对照组就下因果结论，是凭印象
6. **边界**：观察性数据即使分布开，也不能直接推因果；需要实验/准实验（库内无方法）。

#### 评-15 删掉形容词，剩下的是不是事实

1. **知识**：〔本库·方法文档〕「同一个事实，换个词就从描述变成评价，评价会污染后续决策。」「自查句：这句话删掉形容词，还剩下可验证的事实吗？」
2. **出处**：〔本库·方法文档〕`抽样与归因的边界.md` §四。
3. **适用情形**：写复盘结论/对标结论时。
4. **动作**：删掉"搬运/割韭菜/低质/自嗨"等评价词，改成可验证描述（"同一素材多次发布""简介挂课程链接"）。
5. **代价**：人力：5 分钟；时长：5 分钟；现金：0；风险：评价词会污染后续选路
6. **边界**：评价不是不能写，但要与事实分开写；结论段只放事实。

#### 评-16 四问有一个答不上来，只能写"样本内观察"

1. **知识**：〔本库·方法文档〕「四问有一个答不上来，结论就只能写成'**样本内观察**'，不能写成规律。」
2. **出处**：〔本库·方法文档〕`抽样与归因的边界.md` §五。
3. **适用情形**：任何对外结论。
4. **动作**：结论前过四问（分母/没看到vs测到没有/自变量分布/删形容词）；有一问答不上，标题就写"样本内观察"。
5. **代价**：人力：5 分钟；时长：5 分钟；现金：0；风险：跳过四问会把观察当规律
6. **边界**：四问是下限，不是充分条件；过了四问也不等于因果成立。

### D. 不得把推断当数据

#### 评-18 数据缺口要写明缺什么、怎么补

1. **知识**：〔本库·方法文档〕「拿不到依据的写【待验证】并说明缺什么，不许用'通常''一般来说'。」

### E. 变现路径的评估维度

#### 评-19 接服务五维：规模天花板 / 前置条件 / 现金流 / 人设依赖 / 失败样子

1. **知识**：〔本库·方法文档〕接服务：「规模天花板：一个人的交付时间……单人年营收上限约 30–60 万元」「前置条件：至少 3 个可讲的交付案例 + 一套报价口径 + 能约束范围的合同」「现金流：预付 30–50%，尾款验收后结」「对人设依赖：极高」「失败典型样子：接到第 4 单开始同时延期；客户拿你当外包比价；做完不结项、无限加需求」。
2. **出处**：〔本库·方法文档〕`经营-01-五种变现形态.md` §一（【经验帖】/经验推断）。
3. **适用情形**：评估"接服务"这条路。
4. **动作**：按五维逐项写：能接多少单、需要什么前置、现金怎么走、是否依赖本人、失败长什么样；五维缺一不判"通过"。
5. **代价**：人力：30 分钟；时长：30 分钟；现金：0；风险：五维都是经验推断，不是统计
6. **边界**：30–60 万/年为经验推断；客单与交付复杂度不同，上限会变。

#### 评-20 三种经济结构六维：边际成本 / 规模上限 / 前期投入 / 现金流 / 失败模式 / 适配

1. **知识**：〔本库·方法文档〕三种经济结构按六维比较：边际成本、规模上限、前期投入、现金流、失败模式、对本账号适配；卖服务"边际成本高、前期投入低、主线"，卖产品"前期投入高、第 2 年之后"，卖课程"与'我能落地'定位冲突、只作私域转化物"。
2. **出处**：〔本库·方法文档〕`L2-战略-商业模式与定价.md` §一。
3. **适用情形**：比较"服务/产品/课程"三条变现路。
4. **动作**：每条路填六维；"适配"一栏必须写与当前定位的关系，不能只写"能赚钱"。
5. **代价**：人力：30 分钟；时长：30 分钟；现金：0；风险：前期投入/研发周期为经验推断
6. **边界**：产品研发 6–18 个月、课程录制 1–2 个月均为经验推断；真实毛利/获客成本未获取（同文开头）。

#### 评-21 路径必须写前提 / 代价 / 失败样子

1. **知识**：〔本库·方法文档〕「法：路径全集，把可能性摊开。只列路，不选路，每条路写清**前提、代价、失败样子**。」
2. **出处**：〔本库·方法文档〕`道法术器/README.md` 对"法"的定义。
3. **适用情形**：做路径级总表时。
4. **动作**：每条路必须有三栏：前提（需要什么）、代价（人力/时长/现金/风险）、失败样子（怎么识别走不通）；缺一栏就标缺口，不用动作级条目顶。

#### 评-22 评估一条路先问它是否加剧单点/平台/声誉风险

1. **知识**：〔本库·方法文档〕个人品牌四类风险：单点依赖（一个客户 ≥60% 营收）、平台依赖（流量只来自抖音）、声誉风险（一次事故放大）、被抄袭；对冲动作分别是 ≤40%、跨平台/自有表/落地页、打码/不承诺/留记录、投诉不骂战。
2. **出处**：〔本库·方法文档〕`经营-04-品牌风险与对冲.md` §1–§4。
3. **适用情形**：评估任何一条路时。
4. **动作**：每条路加一栏"加剧了哪类风险"；加剧单点/平台/声誉风险的，必须同时写对冲动作，否则不判通过。

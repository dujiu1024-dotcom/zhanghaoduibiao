# 道法术器

四层，从上往下依赖，不许跳层填。

## 各层管什么
- **道**：方向与边界，定死不动。回答我是谁、卖什么、给谁、不做什么。改动必须写明原判断为何不成立。
- **法**：路径全集，把可能性摊开。只列路，不选路，每条路写清前提、代价、失败样子。
- **术**：选定路线后的落地动作。回答选哪条、为什么、怎么拍怎么发怎么成交。
- **器**：工具与库，换得最快。回答用什么装知识、装素材、装数据。

## 谁定谁填
- 道：用户拍板，操盘手起草。
- 法：操盘手填，用户审。
- 术：操盘手填，用户只看结论与代价。
- 器：操盘手定，随时可换。

## 什么时候算填完
- 每个文件的「本文件要回答的问题」全部有答案，且每条答案都有来源 + 位置 + 采集日期。
- 纯主观项必须标【偏好】，不能被当成结论引用。
- 拿不到依据的标【待验证】，写清缺什么、哪天补。

## 依赖顺序
道定完才能填法 → 法摊开才能选术 → 术定了才知道要什么器。

- 道未定时，法只许写候选，不许下结论。
- 法未摊开时，术只许写通用动作，不许写"就选这条"。
- 术未定时，器只许建空库，不许采购或搭建。
- 反向发现道有问题时，先改道，再回改法、术、器，不许下层硬撑。

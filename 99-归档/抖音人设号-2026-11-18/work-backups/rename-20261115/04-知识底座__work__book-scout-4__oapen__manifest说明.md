# OAPEN 取回件 manifest 说明

## 字段

| 字段 | 含义 |
| --- | --- |
| 编号 | 本批顺序号，001 起，与「格优先」顺序一致 |
| 书名 | 取自 DOAB 记录 |
| 出版社 | 取自 DOAB 记录 |
| 原始URL | OAPEN bitstream 原始地址（可复现） |
| 页数 | `pdfinfo` 读数 |
| 有无文字层 | `pdftotext` 全文字符数 > 3000 记「有」，否则「无（疑似扫描件）」 |
| 内页许可原文全文 | 从 PDF 内版权页/许可页抽出的**整句**，逐字保留；不是编者的概括 |
| 许可类型 | 归一为：CC BY / CC BY-SA / CC BY-NC / CC BY-NC-ND / 其他 / 保留所有权利 / 未找到许可 |
| 命中格 | 按标题关键词命中的细类，可多个；与排序用的主格可能不同 |
| 下载状态 | OK / FAIL（FAIL 的备注以 `[类型]` 开头，见下） |
| 引用口径 | 由许可类型自动派生，见下 |
| 文件 | 相对路径；FAIL 时为空 |
| 备注 | 失败类型前缀 + 原始报文；扫描件提示 |

## 失败类型（备注前缀，2026-11-15 起）

| 前缀 | 含义 | 处理 |
| --- | --- | --- |
| `[rate_limited]` | HTTP 429，OAPEN 判为异常请求 | 退避 90/180/300 秒重试，单本最多 3 次 |
| `[server_5xx]` | HTTP 5xx，上游故障 | 退避 10/30/60 秒重试，单本最多 3 次，与 429 分开计数 |
| `[network]` | status 0，连接没建立（实测为 `SSL: UNEXPECTED_EOF`，本地代理断流） | 退避 5/15/30 秒重试，单本最多 3 次 |
| `[epub]` | 返回 ZIP（`PK` 头），该 bitstream 只有 EPUB | 先试同名 `.pdf`；仍失败则标「仅 EPUB，不入库」并移出待办 |
| `[other]` | 其余状态码 | 不自动重试 |

**0 字节文件说明**：`download()` 只在校验通过（HTTP 200 且以 `%PDF` 开头）后才写盘，失败不会产生空文件。2026-11-15 全盘扫描 0 字节 PDF 为 0 个，此前的 `status 0, 0B` 是"连接未建立"，不是"写了个空文件"。

## 断点续跑

manifest 原地更新（写 `.tmp` 后原子替换），不追加重复行。重启时：
- `下载状态 = OK` → 跳过
- 备注含「仅 EPUB」→ 跳过
- 其余 FAIL → 重下并覆盖原行

## 硬规则（写死在 `license.py`，不得违反）

1. **抽不到许可句子时判「未找到许可」，按不可引用处理。**
2. **不许按出版社、DOI、书系、封面标识推断许可。** 判断只用 PDF 内文字。
3. 许可句子取版权页/许可页那一段的完整句，覆盖这几类开头：
   `Open Access: ...`、`This work is licensed under ...`、`This book is licensed under ...`、
   `licensed under a Creative Commons Attribution ...`、德文 `Dieses Buch wird ... veröffentlicht ...`。
4. 抽到的句子整句保留进 manifest，不做概括、不改写。

## 引用口径对照

| 许可类型 | 引用口径 |
| --- | --- |
| CC BY | 可引用 |
| CC BY-SA | 可引用 |
| CC BY-NC | 仅内部判断，对外只可转述观点＋注出处 |
| CC BY-NC-ND | 仅内部判断，对外只可转述观点＋注出处，**不得成段搬用** |
| 保留所有权利 | 不可引用 |
| 其他 / 未找到许可 | 不可引用 |

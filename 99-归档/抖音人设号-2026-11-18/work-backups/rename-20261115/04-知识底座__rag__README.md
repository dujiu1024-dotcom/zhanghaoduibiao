# 检索底座（rag）

单文件 SQLite 库，零服务、离线可跑。三条检索通道并行：中文二元字组倒排（原字面路的升级版）、人工概念标签、bge-m3 向量（ollama 本地）。命中必须带 **路径 + 段号（或法条号）+ 质量档**，缺一不输出。当前库：68 篇文档 / 2718 段（可引用 2103、仅参考 606、不可引用 9）。

旧的 `knowledge/sources/index/`（postings.json / docs.json）**原样保留未删**，评估里作为对照基线。

## 三条命令

```bash
cd 04-知识底座/rag

# 1) 查（默认 字面+标签+向量 融合，取前 5）
.venv/bin/python rag.py search "为什么人看到一半就划走了"

# 2) 增量入库：扫描 knowledge/ 下所有 md + metadata 登记的法条/书籍全文
#    文件没变则跳过；改了则删旧段重切、重算向量；重复执行不产生重复行
.venv/bin/python rag.py ingest

#    只入某个新文件
.venv/bin/python rag.py ingest ../../some/新资料.md

# 3) 重建（删库重来，含全部向量与图谱）
.venv/bin/python rag.py rebuild
```

辅助命令：

```bash
.venv/bin/python rag.py stats                  # 文档/段/词/向量/标签/图谱规模
.venv/bin/python rag.py search "报价" --quality 可引用        # 只要可引用档
.venv/bin/python rag.py search "报价" --mode literal          # 纯字面
.venv/bin/python rag.py search "报价" --mode literal+tag      # 字面+标签
.venv/bin/python rag.py search "报价" --json                  # 机器可读（含无答案状态）
.venv/bin/python rag.py search "报价" --sim-floor 0.60         # 临时放宽相关性下限
.venv/bin/python rag.py graph --neighbors theory-recall-ranking   # 图谱邻居
.venv/bin/python rag.py graph --search 完播                      # 搜节点
.venv/bin/python rag.py retag                  # 只重打标签（改了同义词表后）
.venv/bin/python rag.py eval                   # 有答案 20 条 + 无答案 12 条，四组对照
```

## 一次查询长什么样

```
QUERY: 个人信息保护法第四条讲的是什么   mode=hybrid   hits=3

1. [原文命中] 04-知识底座/knowledge/sources/fulltext/law/pipl.txt  第四条  可引用  (literal#1 vector#1)
   个人信息保护法 / 第一章 总 则
   第四条 个人信息是以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息……
```

- **路径**：`source_path`，md 指回原始 md，法条指向 `fulltext/` 下的原文。
- **段号**：md 用 `§n`（n 为文档内段序，长段拆分为 `§n.2`）；法条用 `第X条`。现有全文没有 PDF 页码，故不输出页码，不建议把 `§n` 当页码引用。
- **质量档**：来自 `metadata.csv`：`可引用`（现行法条、原著原文）/ `仅参考`（本库撰写的二手提炼）/ `历史文本|已废止`（文本真实但规则已被替代，保留全文与条号，只用于查沿革）/ `不可引用`（当前 9 段：名实不符的 Euclid 旧档）。
- 括号里的 `literal#3 vector#5 tag#12` 是该命中的通道与名次，便于判断这条为什么被召回。

**没答案时不会硬凑：**

```
QUERY: TikTok 美国小店入驻保证金多少   mode=hybrid   【库内无相关内容】
判定：向量最高相似度 无（成答下限 0.66）；字面最高覆盖率 0.18（候选召回 0.32，
     单独成答需 0.40 且问句未登录词占比 ≤ 0.50，当前 0.59）。
未返回任何段落。建议：
  - 换关键词：用本库会用的说法（平台黑话换全称、把问题拆成单个概念）
  - 补源：该问题的出处本库没有登记，需要先找可核来源再入库
```

带质量档过滤时若只有放宽后才命中，会单独列出并标注：

```
【库内无相关内容】
建议：
  - 放宽质量档后有 5 条线索（标注：放宽了质量档才有命中，不构成答案）：
      04-知识底座/knowledge/methodology/L3-战术-跨平台改写.md · §2 · 仅参考
```


**两种命中必须分清：**

```
2. [标签命中] 04-知识底座/knowledge/methodology/心理-01-准社会关系.md  §1  仅参考  (翻车←"翻车" 失败←"失败")
   原文：……
   注：标签只说明主题相同，不能当原文引用；引用需回到原文核实。
```

- `[原文命中]`：字面或向量在段落原文里匹配到，可回原文核对。
- `[标签命中]`：只由人工同义词表关联到（如「划走」→ 完播），**原文未必直接回答该问题，禁止当引用依据**。

## 质量档过滤

```bash
.venv/bin/python rag.py search "个人信息处理规则" --quality 可引用   # 只返回现行法条/原著
.venv/bin/python rag.py search "完播率怎么看" --quality 可引用        # 0 条：本库没有可引用档讲过完播
.venv/bin/python rag.py search "增值税 小规模纳税人 税率" --quality "历史文本|已废止"   # 只查已废止旧法
```

过滤是硬过滤，不降级、不混档；多选用**逗号**分隔（质量档名本身可能含竖线，如 `历史文本|已废止`，不按竖线拆）：`--quality 可引用,仅参考`。已被替代的旧法统一标 `历史文本|已废止`，永远不会出现在 `--quality 可引用` 里。

## 表结构

| 表 | 内容 |
| --- | --- |
| `docs` | 一篇文档一行：`source_path`、题名、质量档、sha1、字符数、metadata 原样 JSON |
| `segments` | 段落：`doc_id`、段序、章节、`locator`（`§n` / `第X条`）、质量档、`text`（原文）、`embed_text`（`题名 > 章节` + 原文） |
| `terms` | 二元字组倒排：`(gram, seg_id)`，用于字面路 |
| `segment_tags` | 人工概念层：`(seg_id, topic, synonym)`，同义词多值 |
| `seg_vec` | sqlite-vec 虚表，`float[1024]` + cosine，rowid = `segments.id` |
| `graph_nodes` / `graph_edges` | 图谱节点与边（从 `图谱/graph.json` 导入，217 节点 / 318 边） |

分段规则：md 按标题分节、按空行分段，长段按句号切并保留表格表头；法条按「第X条」切，`第X章/节` 作为章节；纯文本按空行切。段落原文与用于嵌入的前缀文本分开存。

## 增量与幂等

- `ingest` 对每篇文档算 sha1：未变 → 跳过（0 段写入）；变了 → 删该文档全部段、倒排、标签、向量后重切重算。
- 新增 md 默认质量档 `仅参考`；要标成 `可引用`，先在 `knowledge/sources/metadata.csv` 登记（`本地路径` 对应 fulltext 文件、`来源URL` 对应 md 路径），再 `ingest --force <文件>`。
- 改 `TOPIC_LEXICON`（同义词表）后跑 `retag`，只重打标签，不重算向量。
- 实测：连续跑两次 `ingest`，第二次 `new=0 updated=0 skipped=68 segments=0`，段数 2718 → 2718，无重复行。

## 依赖（本机已装好）

- `sqlite-vec 0.1.9`：装在 `rag/.venv`。系统 Python 是 PEP 668 托管环境，所以用 venv，不污染全局。
- 向量：ollama + `bge-m3`（1024 维），`http://127.0.0.1:11434/api/embed`。可用环境变量 `OLLAMA_URL` / `EMBED_MODEL` 覆盖。
- 若换嵌入模型，必须同步改 `EMBED_DIM` 并 `rebuild`；维度和虚表不一致会直接报错退出。
- 若 ollama 不可用：`search` 会打印警告并降级到字面+标签（不中断查询）；`ingest/rebuild` 会退出并列出替代选项（启动 ollama / 换模型 / 远端 embedding 需 key），不会自行安装大依赖。

## 相关性下限与「无答案」

三路各自设闸，任何一路过线才算有答案；都不过线时 **返回 0 条段落**，只给诊断和建议。

| 闸门 | 默认值 | 作用 | 改法 |
| --- | --- | --- | --- |
| `SIM_FLOOR` | `0.66` | 向量相似度（1 − cosine 距离）低于它直接丢弃，不进融合、不进前五 | `--sim-floor` / `RAG_SIM_FLOOR` |
| `ANSWER_MIN_COVERAGE` | `0.40` | 字面路单独成答所需的最小查询覆盖率（命中的字组 IDF 占问句总 IDF） | `RAG_ANSWER_MIN_COVERAGE` |
| `OOV_FLOOR` | `0.50` | 问句里「库里不存在的字组」IDF 占比上限，超过说明本库缺这个词 | `RAG_OOV_FLOOR` |
| `COVERAGE_FLOOR` | `0.32` | 字面候选召回线（低于它不进融合，但也不等同于答案） | `RAG_COVERAGE_FLOOR` |

为什么不是一个阈值：在 32 条评估集上，无答案问题的向量最高相似度能到 0.642，有答案问题最低只有 0.528，两个分布重叠；只靠向量下限，要么漏答、要么放进来一批硬答。实测加字面闸门后才把硬答压下去（否则问句里只要出现「抖音」「怎么」就会被长段落硬答）。

标签层单独命中 **不构成答案**：它只说明主题相同，不返回、不参与成答判定。

## 评估

见 [eval/report.md](eval/report.md)。两组问题集：[questions.jsonl](eval/questions.jsonl)（有答案 20 条）、[questions_negative.jsonl](eval/questions_negative.jsonl)（故意问库里没有的 12 条）。

| 方案 | 有答案命中率 | 漏答率 | 无答案硬答率 |
| --- | --- | --- | --- |
| 旧索引（原 postings.json） | 0/20 | 20/20 | 0/12 |
| 纯字面（二元字组） | 12/20 | 5/20 | 2/12 |
| 字面 + 标签 | 14/20 | 5/20 | 2/12 |
| 字面 + 标签 + 向量 | 18/20 | 0/20 | 2/12 |

加闸门前 hybrid 是 20/20、无答案集未测；加闸门后命中降到 18/20（q12、q13 的预期出处被挤出前五），换来的是 0 漏答、12 条无答案问题里 10 条正确拒答。阈值扫描对照在 report 的「阈值依据」一节：0.60 时 20/20 命中但硬答 4/12；0.68 起出现漏答。

已知两类错误（当前取值下）：

- **漏答**：0/20（没有把有答案的问题拒掉），但有 2/20 的预期出处没进前五（属于排序损失，不是拒答）。
- **硬答**：2/12 = 17%，是 `n02 2025 年抖音日活` 和 `n03 小红书封面文案怎么写`。库里确有抖音数据、小红书平台对比的段落，字面覆盖率 0.6 以上，闸门放过去了。要再压这两个，只能把 OOV 上限收到 0.40，代价是把 `q01` 一起拒掉——这是取舍，不是已解决。

读数字前先看 report 的「口径与偏差」：路径级命中、两个集合都非盲测、阈值是在这两组上选的（换问题要重校准）、旧索引 0 命中是「全二元组 AND + 全串匹配」的既有设计。

## 已知边界（未解决，别当已解决）

1. **仍有 2/12 硬答**（见上），且无答案集的判定偏严：返回任何段落即记硬答。彻底解决要加一层「答案是否真的回答了问题」的判断（模型或人工），当前没有。
2. **阈值过拟合风险**：0.66 / 0.40 / 0.50 是在 20+12 条上选的分区；换领域或换问法要重跑 `eval` 校准，别把它当普适常数。
3. **《修辞学》已换成真文本，旧档降级但未删**：`fulltext/books/rhetoric.txt` 实际是 Euclid《Elements》（Perseus `1999.01.0086` 本身就是 Euclid），已把该条质量档降为 `不可引用` 并在 `备注` 写明"名实不符，待替换"；真正的亚里士多德《修辞学》另存为 `fulltext/books/rhetoric_aristotle.txt`（W. Rhys Roberts 英译，1924 公版，MIT Internet Classics Archive，381,292 字符，三卷 60 节），质量档 `可引用`。检索时两条并存，只引 `rhetoric_aristotle.txt` 那条。
4. **没有页码**：现有 fulltext 无 PDF 分页信息，`locator` 只能到段号/法条号；《修辞学》的节次在 `section` 里（`BOOK I / Part 2`），不是出版页码。
5. **标签层是保守的**：只收录语料中出现过的说法（`掉播`、`踩坑` 全库 0 次，已剔除）；标签命中只做主题定位，不做语义断言。
6. **法条段很短**：民法典约 1260 条多为 20–70 字，向量区分度低，查询时会与业务文档混排，靠质量档过滤或关键词收窄。
7. **来源过滤**：`knowledge/sources/*.md`（采购清单、审计报告）未入库，与旧索引口径一致，避免把"关于出处的报告"当成知识本身。
8. **已废止法规单独归档**：`增值税暂行条例`（2026-01-01 被《增值税法》替代）标为 `历史文本|已废止`，不进 `--quality 可引用`；同类被替代/修正前的版本一律按此标，保留全文与条号，只在查沿革时用。

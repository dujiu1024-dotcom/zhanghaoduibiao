# 路径矩阵：达成目标的所有走法

> 用途：把「立人设 → 万粉 → 接单」这一串目标拆成可挑选的走法，摊开，不下结论，不替你做选择。
> 本文件不排序、不打分、不写"推荐"。四轴之间可以任意组合，组合后的冲突由你判断。
> 每条固定六字段：名称 / 具体怎么做 / 成本 / 见效速度 / 对人设的增益 / 有没有条件做。

## 读法

- **成本**：时间按"每条内容"或"每次动作"估算；钱按单条、单次或每月估算。带 `†` 的数字为**无依据，待验证**（未实测、未询价、未跑过），不带 `†` 的来自本项目已有记录或公开页面。
- **本人出面**：`是`＝需要你真人出镜/到场/开口；`部分`＝需要你的声音或手但不露脸；`否`＝我可以独立完成。
- **见效速度**：写"几天看到第一个信号"，信号是可在后台或评论区直接看到的现象，不是感觉。
- **人设增益**：判据只有一条——这条路让"你这个人"更清楚还是更模糊。加分＝更清楚；中性＝不改变；减分＝更模糊。
- **条件**：`现在能做`＝今天就能开始；`需额外资源`＝写明缺什么；`做不了`＝写明为什么。
- 四轴条目总数 118 条：涨粉 29、人设 27、转化 32、交付 30；另有 20 条被排除的路单独说明。

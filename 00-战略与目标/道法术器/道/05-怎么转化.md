# 怎么转化
状态：已填（主线为有依据的推断，含平台规则原文；转化率数据未获取）

## 本文件要回答的问题
1. 观众从看到内容到付费，走哪条主线？
2. 承接放在哪里，平台允许放在哪里？
3. 什么算一次转化，记哪个数？
4. 哪些动作是红线？
5. 转化做不做得到，靠什么判断？

## 结论
转化只走一条主线：内容 → 抖音站内私信／主页组件 → 客户主动留资 → 一对一诊断 → 书面范围与报价。转化指标只记"有效私信数"（出现"多少钱／能不能做"的条数），不拿粉丝数当转化。内容、简介、评论里不留微信、电话、二维码，不说"加我""私信我"；具体接法与话术待法层展开。
